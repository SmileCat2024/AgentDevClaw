## 模型配置

Agent 的所有能力都由大模型驱动，您需要在AgentDevClaw中添加模型「预设」，才能让Agent正确运行，您可以随时按需添加、切换。

### 1.打开模型配置

1. 点击右下角的设置按钮（齿轮图标）。
2. 在弹出菜单中点击「模型配置」。

![打开模型配置](./assets/model-config-entry.png =800x left)

### 2.添加一个预设

点击底部「+ 添加预设」，填写连接信息，标准的配置包括：

| 字段 | 说明 |
| --- | --- |
| 名称 | 自己好认的名字，如「智谱 GLM-5.3」，与API请求无关可以随便命名 |
| 接口协议 | Anthropic / OpenAI Chat / OpenAI Responses |
| Model | 模型 ID，如 `glm-5-turbo`，这是API请求发往后端的模型名，需要严格按照供应商指南填写 |
| Base URL | 服务地址，从模型服务商处获取 |
| API Key | 服务商签发的密钥 |

在接口协议下拉框中，还可以使用OpenCode / OpenAI Auth两种方式进行登录，两者底层分别使用OpenAI Chat 和 OpenAI Responses协议链接 

表单下方还有三组可选项：

- **模型能力**：模型支持深度思考或图片输入时，打开「启用思考」「启用视觉输入」开关；
- **生成参数**：上下文长度、压缩阈值、输出上限、温度，留空走默认值；
- **高级**：自定义请求头，部分服务商网关需要。

保存后点击预设卡片即可激活，顶部横幅会显示当前生效的预设。设置窗口内还有「语音模型」标签页，用于配置语音输入模型，用法相同。

### 3.会话中切换

您可以在对话区输入框的中的模型选择器中，切换当前会话的模型，配置将立即生效，无需重启。特别注意，

### 4.按角色指定模型

编程小助手工作空间支持按角色指定模型：在工作空间卡片上点击「工作空间设置」，可为「编程小助手」「Coder」「系统管理」分别指定模型；不指定则跟随全局默认。

### 5.常见问题

**Q1：我修改了模型配置，为什么会话里的Agent没有跟着变？**

修改某个模型配置之后，已运行的，正在使用该模型配置会话不会自动刷新，您需要通过重启Agent会话，或在输入框中的模型选择器中点击配置名称手动刷新

**Q2：为什么模型输出经常会被中途打断？**

请仔细检查模型生成参数是否填入合适的思考、输出token值。输出token值指的是思考token+后续正文输出/工具调用的token总量预算上限

**Q3：模型配置的URL端点不对？**

您需要关注模型供应商提供的端点后缀情况要求，特别是带不带 `/v1`的问题。在AgentDevClaw中，Anthropic 协议的 baseUrl 带不带 `/v1` 都行；OpenAI 系协议（chat / responses）必须自己带 `/v1`
