# 技能（Skills）配置

技能是给 Agent 扩充领域知识与专门能力的文档包：一套工作方法、一个领域流程、某种工具的用法，都可以装成一个技能，Agent 需要时自动加载。本文讲怎么装技能、怎么写技能。

## 技能装在哪

| 目录 | 默认 | 说明 |
| --- | --- | --- |
| 项目 `.agentdev/skills/` | 扫描 | 每个技能一个子目录；跟着项目走，可进版本库共享 |
| 项目 `.claude/skills/` | 不扫描 | Claude Code 格式的技能目录；在设置中开启扫描后直接复用，不用搬迁 |
| 额外目录（extraDirs） | 空 | 在设置中登记的任意目录；登记在全局层后对本机所有项目生效 |

从 Claude Code 项目迁移：项目里已有 `.claude/skills/` 的，开启扫描即可；新装技能建议放 `.agentdev/skills/`。

## SKILL.md 怎么写

每个技能是一个目录，里面必须有一个 `SKILL.md`：

```markdown
---
name: my-skill
description: 一句话说明这个技能是什么、什么时候用。
---

# 技能标题

正文：告诉 Agent 这个技能该怎么做事。指令写具体、可执行。
```

两个要点：

- **frontmatter 的 `description` 决定触发**：Agent 是根据描述判断何时使用技能的，把「什么时候用」写清楚，比名字更重要；
- **渐进披露**：正文只写主干；详细资料放同目录 `references/` 子目录（如 `references/details.md`），正文里注明需要时读取。这样技能清单保持轻量，细节按需加载。

目录内的其他文件（脚本、模板等）随技能一起存放，正文中以相对路径引用。

## 技能怎么触发

三种方式，效果相同：

1. **明确指名**：在对话里直接说「用某某技能做这件事」；
2. **自动判断**：对话内容与技能描述匹配时，Agent 自己判断有必要就会加载对应技能；
3. **命令菜单**：输入框输入 `/` 唤起菜单，技能以 `skill.` 前缀列出，选中后随下一条消息加载。

## 生效时机

- **新对话**：装好技能后创建的对话直接可用；
- **已运行的对话**：技能在会话启动时加载，装了新技能的老对话要重启后才能用——在左侧列表该会话上右键 →「重启 Agent」。重启的只是这个会话的运行时，不影响其他会话，也不用重启整个程序。

## 扫描与目录配置在哪改

设置菜单 →「全局 Feature 设置」中找到 skill 相关配置项：是否扫描 `.claude/skills`、追加额外目录等。工作空间级的覆盖在对应工作空间的设置中调整。

## 常见问题

**装了技能没生效？**

确认目录位置（项目根下 `.agentdev/skills/<技能名>/SKILL.md`）、frontmatter 的 `name` 与 `description` 齐全；已运行的对话按上文「生效时机」重启该会话。

**想验证技能已被识别？**

输入 `/` 看命令菜单里是否出现 `skill.<name>`，或在对话里直接问 Agent 当前有哪些技能。
