# 快速上手

这一页带你跑通最小闭环：打开工作空间、开始第一次对话、查看结果。

## 启动

```bash
npm install
npm run build
npm start
```

浏览器打开 `http://localhost:1420` 即可看到主界面。

## 第一次对话

1. 在左侧选择「编程小助手」工作空间。
2. 选择一个项目目录，新建对话。
3. 输入需求，Agent 会规划并执行。

对话过程中可以随时：

- **分支**：从某条消息节点另起一条思路；
- **精简**：裁剪早期历史或压缩为摘要；
- **checkpoint**：保存当前会话状态，随时回滚。
