# 基础概念

在动手之前，先建立几个核心概念的心智模型。

## 工作空间

工作空间是 AgentDevClaw 的功能单元。每个工作空间聚焦一件事：AI 编程对话、Feature 制造、IM 消息接入等。左侧列表就是全部工作空间的入口。

## 会话

会话是一次具体的交互过程。会话绑定一个项目目录，Agent 的所有工具操作都在这个目录下进行。会话可以分支、精简、checkpoint 管理。

## Feature 与 Agent

- **Feature** 是一个能力包，提供工具、界面块或工作流。
- **Agent** 是 Feature 的装配体：多个 Feature 组合出一个完整的智能体。

| 概念 | 类比 | 说明 |
| --- | --- | --- |
| Feature | 插件 | 提供独立能力 |
| Agent | 宿主 | 组合 Feature 并暴露交互入口 |
| Runtime | 进程 | Agent 的运行实例 |
