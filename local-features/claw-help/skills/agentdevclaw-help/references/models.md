# 模型配置

模型配置回答一个核心问题：我手上有一份大模型的访问凭证，怎么接进来用。按凭证类型分三条路径，先判断用户属于哪一种，再给对应步骤。所有配置的入口都是**设置 → 模型配置**（右侧栏底部齿轮图标），配置一次后对所有工作空间可用。

## 先判断：你的凭证是哪一类

| 你手上的东西 | 对应路径 |
|---|---|
| ChatGPT / Codex 订阅（Plus、Pro 等套餐） | 路径一：Codex 登录 |
| OpenCode 订阅（OpenCode Zen / OpenCode Go） | 路径二：OpenCode 登录 |
| API key（Anthropic、OpenAI 或任意兼容服务商，含自建中转） | 路径三：自定义模型 |

三条路径可以同时配置多个，各自成为一条「预设」，会话里随时切换。

## 路径一：Codex 订阅登录

设置 → 模型配置 → 「使用 Codex 模型」：连接 OpenAI 账户，登录后即可使用 Codex 订阅套餐内的模型，无需 API key。

**网络前提**：Codex 服务需要通过代理访问。登录前先完成代理配置（见下文「网络代理」一节），否则登录与调用都会失败。配置页提供连通性测试，可直接验证代理是否可用。

### 标准 / Fast 倍率模式

设置 → 模型配置 → Codex（或总览）→ 编辑模型预设 → **倍率模式**：选择「标准」或「Fast」，然后保存。不需要手填请求头或 JSON；旧的 Codex 登录预设也提供这个控件。打开编辑页时会加载模型目录，Fast 等可选档位及说明以服务方声明为准；目录读取失败时先检查网络，再刷新目录。

标准使用默认服务；Fast 会发送 `service_tier: "priority"`，并自动生成匹配模型与档位的 Codex 路由提示头。Fast 可能消耗更多额度，是否实际获得优先服务由服务端决定，不能仅凭请求成功或单次耗时判断。保存后，运行中的会话需要重新选择该模型预设，才能重新创建使用新参数的模型实例。

预设的「高级 → 额外请求体参数」是独立于自定义请求头的通用 JSON 对象配置，供 OpenAI Chat、Responses、Anthropic 协议的服务商扩展使用。模型、消息、工具和流式控制等运行时字段不能覆盖。Codex 的 `service_tier` 统一由上方控件编辑，不在高级 JSON 中重复填写。

## 路径二：OpenCode 订阅登录

设置 → 模型配置 → OpenCode 页：登录 OpenCode 账户（Zen / Go 两种套餐形态），使用订阅内的模型。同样建议先确认代理可用。

## 路径三：自定义模型（API key / 兼容端点）

设置 → 模型配置 → 「添加自定义模型」。支持三种主流 API 协议，覆盖绝大多数服务商与中转站：

- **OpenAI Chat Completions**（`/v1/chat/completions`，最通用的兼容格式）
- **OpenAI Responses**
- **Anthropic Messages**

需要填写的信息：API key、接口地址（Base URL，官方默认值已内置，中转或自建端点填自己的地址）、模型名。国内各服务商的兼容网关（中转站）只要兼容上述协议之一即可接入，填它的 Base URL 与模型名即可。

## 网络代理

入口：设置 → 网络代理。适用于 Codex、OpenCode 等需要代理才能访问的服务。

配置项：

- **启用开关 + 代理地址**：填入代理服务器地址（如 `http://127.0.0.1:7890`，以本机代理软件的实际端口为准）；
- **保存即全局生效**：无需重启；
- **连通性测试**：保存前可测试代理地址是否可用；
- **系统代理自动检测**：界面会显示检测到的系统代理，可直接采用。

## 会话内切换模型

配置好的预设无需回到设置页切换：对话输入框旁的模型切换器可直接为当前会话选择模型，即时生效。

## 常见问题

**凭证失效了（提示 401 / 未授权）怎么办？**
重新登录（订阅型）或更新 API key（自定义型）即可。更新后无需手动重启会话：系统会自动通知各会话刷新凭证，正在进行的对话会使用新凭证继续，不用重开会话。

**模型响应很慢或中途卡住？**
默认行为：等待首个响应最多 120 秒、流式输出中途停顿最多 60 秒，超时自动重试（最多 5 次）。偶发网络抖动会自动恢复；持续超时先检查代理与网络，再检查服务商状态。

**配好的模型没出现在切换器里？**
回到设置 → 模型配置确认该预设已保存且未被禁用；仍异常时按 references/troubleshooting.md 排查。
