# 会话管理

每个会话都保留一段独立的工作过程。您可以继续旧会话、从中途另开分支，或在发错消息时回退；需要引用另一段对话时，也可以把它作为上下文带入当前会话。

## 继续之前的对话

在左侧会话列表中找到目标会话并点击，即可查看并继续。会话列表按项目目录分组，切换项目后仍可重新打开对应历史会话。

## 常用会话操作

在会话条目上右键，或点击条目旁的「⋯」菜单：

- **创建分支**：选择一个历史轮次作为分支点，从那里开始新会话。原会话保留，适合尝试另一条方案；
- **重命名、归档或删除**：整理会话列表。归档会收起暂时不用的会话；删除会移除会话记录；
- **精简历史、总结历史**：处理较长对话的上下文。大多数情况下，选择「精简历史」并直接确认即可。精简面板的操作细节见[上下文接续与精简](../进阶用法/上下文接续与精简.md)，两者的取舍见[上下文管理](../进阶用法/上下文管理.md)。

编辑自己发出的消息时，还可以选择「回退到此轮」：该轮之后的消息会被移除，内容回到输入框供您修改后重新发送。若想保留原有走向并尝试不同方案，使用「创建分支」更合适。

## 引用另一段对话

在输入框点击「+」并选择「会话」，挑选要引用的历史会话；也可以把左侧列表中的会话拖到输入框。引用随下一条消息发送，助手会按需读取相关内容。

![把历史会话拖入输入框](./assets/跨对话记忆拖拽.mp4 autoplay loop muted =65%)

也可以复制会话 ID 并在对话中告诉助手要读取它。完整操作与限制见[跨对话记忆](./跨对话记忆.md)。
