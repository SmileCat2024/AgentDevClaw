## IM 渠道

IM 渠道工作空间把 QQ、微信、飞书、企业微信等 IM 平台的机器人接入 AgentDevClaw：外部用户在 IM 里发消息，消息被路由到工作空间会话处理，回复再传回 IM。您可以随时把一条 IM 线路转接到任意工作空间的活跃会话。

### 1.配置渠道

在工作空间首页打开「渠道配置」，选择渠道并填写凭据：

| 渠道 | 凭据来源 |
| --- | --- |
| QQ | 开放平台的 App ID、Client Secret、Account ID |
| 微信 | 扫码绑定个人号 |
| 飞书 | 开放平台应用的 App ID、App Secret |
| 企业微信 | 机器人的 Bot ID、Secret |
| Rokid 眼镜 | 设备「开放 Claw」配对页面的配对码与密钥 |

保存后渠道卡片会显示已绑定状态。所有渠道配置同时存在，可按需切换使用。

### 2.启动门户代理

门户代理是 IM 消息的入口网关：

1. 在「门户代理」卡片中选择**当前渠道**。
2. 点击「新对话」（或打开一条门户对话记录），门户代理会话将按所选渠道建立连接。
3. 勾选「Claw 启动时自启」，服务启动后自动恢复门户代理，无需手动操作。

### 3.转接 IM 线路

门户代理内置接线员工具，在对话中直接说需求即可，例如「把线路 1 接到编程小助手的当前会话」。接线员会：

1. 查看所有 IM 线路的绑定状态；
2. 浏览各工作空间当前在线的会话；
3. 将指定线路连接（或断开）到目标会话。

连接后，该线路收到的 IM 消息由目标会话的 Agent 处理，回复自动传回 IM；断开即恢复门户代理自己处理。「通道配置」区可以总览每条线路当前的载体与绑定对象。
