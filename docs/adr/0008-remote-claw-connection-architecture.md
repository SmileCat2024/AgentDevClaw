# 0008 — 远程连接：远程权威 + 无状态透传 + SSH 单隧道

- **Status**: Accepted
- **Date**: 2026-08-26
- **来源**: 2026-07-23 至 2026-08-26 三轮 grill 会话（总体架构 Q1–Q33、Phase 1 切片 Q38–Q43，全部经用户批准）

## Context

Claw 的定位是本机运行的 Agent 工作台，但用户实际拥有"部署在远程服务器上的 Claw 实例"，目前只能开第二个浏览器窗口直连远程端口。目标体验是：远程服务器上各工作空间的 Agent 出现在本地页面左侧列表中（`服务器名：项目` 分组），与本地工作空间并列，操作心智完全一致。

硬性约束：

1. **可靠性是第一诉求**——连接必须稳定，失败必须显式，不能出现"看起来发出去了其实没有"。
2. **Feature 不分叉**——未来任何 Feature / 前端功能只写一套逻辑，系统自动决定目标 是本地还是远程；不能每加一个功能就重做一遍通讯。
3. **轻量**——不引入需要长期维护的重型基础设施。

前置条件已就绪：服务端 current agent 语义已从框架移除；Phase 0（[ADR-0006](0006-local-explicit-resource-targeting-first.md)）完成了显式资源寻址标准化，`request-target.js` 已具备扩展多目标解析的形态。

## Decision

### 1. 远程完整 Claw 实例是唯一权威执行端

Runtime Plane（消息/工具/Todo）、Session Plane（会话/分支/精简）、Host Plane（配置/编排/进程）全部在远程执行。本地只负责发现、寻址、转发、聚合展示与错误呈现。禁止任何形式的"本地替身"：不创建远程工作的本地镜像 Session，不在本地执行远程逻辑，不因连接失败降级为本地执行。

### 2. 本地零业务状态镜像

本地不缓存远程消息、Todo、Session、配置等业务真值；每次请求透传读远程真值。断线时保留已渲染内容但明确标记断开，不进行状态追赶；隧道恢复后下一次轮询自动拿到正确状态，恢复零代码。放弃本地镜像 + 推送方案：缓存一致性、断线追赶、跨仓库框架改动的复杂度，远超它节省的轮询 RTT（约 30–100ms，叠加在秒级轮询节奏上无感）。

### 3. SSH 本地端口转发是唯一传输；只转发远程 1420

远程 ViewerWorker (2026) 永不直接暴露，所有请求经远程 Claw Server (1420) 的既有代理路径。传输对路由层不可见：`resolveViewerOrigin` 只返回 `http://127.0.0.1:<localPort>`，端口背后是 SSH、Tailscale 还是别的，路由层不知道也不需要知道。未来更换传输 = 映射为本地端口，路由零改动。

### 4. 连接命名空间：`remote:<connId>:<id>`

不同机器生成相同 runtime ID 是必然事件，命名空间是必须品。编码/解码/重写全部由服务端完成，前端与 Feature 把它当不透明字符串。命名空间键同时用于工作空间分组（`服务器名：项目`），避免与本地同名项目冲突。

### 5. Host-scoped 请求默认本地，远程必须显式

无 `connectionId` 的 Host 请求只表示本地宿主；禁止从页面焦点、列表位置推断目标。防止"看了一眼远程 Agent，本地配置就写到远程去"。

### 6. 远程零改动是长期约束

远程就是一台正常 `npm start` 的 Claw，不为"被连接"做任何适配。握手复用现有端点组合（`/protoclaw/health` + `/protoclaw/app_info` + `/api/agents`），不新增远程服务、守护进程或专用协议。远程独立升级不影响连接。

### 7. 失败三分类，显式呈现

- `transport_unavailable`：隧道不通（SSH 进程退出/网络断）；
- `target_not_found`：隧道通但远程 Claw 未运行；
- 版本不匹配：握手可完成，标记警告但不阻断。

断开的连接在列表中保留身份并显示断开状态；写操作默认禁用；不伪造成功；不做隐式离线队列。读操作可自动重试，写操作必须有幂等键（复用既有 operationId / idempotencyKey 体系，不另造平行概念）。

### 8. 分阶段交付，聚合单位 = 工作空间

- **Phase 1**：连接基础 + 只读远程视图——远程工作空间以 `服务器名：项目` 出现在左侧列表，消息流/Todo/Hook/模板只读可用，输入区显式禁用。

  呈现层后续由 [ADR-0010](0010-sidebar-unified-projection.md) 细化：`服务器名：项目` 落为远程项目组标签（`主机名：目录名`），嵌在对应本地工作空间入口之下；连接本身不产生侧栏层级。本篇其余决策（权威端、传输、命名空间、失败分类）不变。
- **Phase 2+**：写操作（输入/中断，需幂等契约）、Session 工作流、Host 管理面。

聚合单位是**工作空间**而非单个 Agent：工作空间通常代表一个 Agent，但可以承载多个 Agent/会话身份；这与本地列表既有心智一致，远程连接是对它的自然扩展。

### 9. manual 隧道模式是永久诊断路径

连接支持 `manual`（用户自建隧道，Claw 只读本地端口）与 `managed`（Claw 托管 SSH 子进程：keepalive、退避重连）两种模式。manual 不是脚手架，是排查 SSH/网络问题的产品能力，且让路由/握手/视图可以先行独立验证。

## Consequences

- 轮询每次多付一个 RTT，换取零镜像复杂度与零代码恢复——体感与本地一致的代价可接受。
- 隧道本地端口（127.0.0.1，无认证）对本机所有进程可见：同机威胁模型下已接受，记录为已知边界；未来环境恶化时在本地代理层加 token，架构有位置。
- 两端版本漂移靠 `app_info`（clawVersion + framework.version）握手校验，不匹配标记不阻断，责任在部署者。
- 远程 Claw 与本地 Claw 的 Feature 集合可能不同：只读视图按远程真实返回渲染，本地不补偿缺失能力。
