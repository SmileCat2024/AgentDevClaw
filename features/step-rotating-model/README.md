# @agentdev/step-rotating-model

step-rotating-model feature for AgentDev.

## Installation

```bash
npm install @agentdev/step-rotating-model
```

## Usage

```typescript
import { Agent } from 'agentdev';
import { StepRotatingModel } from '@agentdev/step-rotating-model';

const agent = new Agent().use(new StepRotatingModel());
```

## Development

```bash
npm install
npm run build    # 或 npm run dev 监听模式
```
