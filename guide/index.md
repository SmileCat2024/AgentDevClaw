# AgentDevClaw 使用指南

AgentDevClaw 是一个以 Agent 为中心的本地工作台。它把几类 AI 工作空间装在一起：写代码的「智能编码空间」、接入 IM 消息的「IM 渠道」，以及 Feature 仓库、调度台等配套单元。在每个工作空间里，Agent 在你指定的项目目录中读代码、改代码、执行命令，直到把事情做完。

## 先认识四个概念

- **工作空间** —— 功能单元，每个聚焦一类事。左侧列表就是全部工作空间的入口。
- **会话** —— 一次具体的交互过程。会话绑定一个项目目录，Agent 的所有操作都发生在该目录内；会话可以分支、精简、checkpoint 管理。
- **Feature** —— 能力包，这是理解 AgentDevClaw 的关键。你在对话里用到的每一个工具，背后都是一个 Feature：执行 Shell 命令是一个 Feature，Web 搜索是一个 Feature，接入 QQ / 微信 / 飞书也各自是一个 Feature。
- **Agent** —— Feature 的装配体。Feature 只提供工具、界面块或工作流，本身不构成产品；Agent 把一组 Feature 装配成完整的智能体——比如「编程小助手」就是 Shell + LSP + Web 搜索 + 待办清单等一组 Feature 的组合。

每个 Feature 都有自己的参数，参数按**全局 → 工作空间 → 目录**三个层级继承，越具体的层级越优先。这套配置体系的工作方式与操作入口见[基础概念](./01-基础概念.md)。

## 启动

```bash
npm install
npm run build
npm start
```

浏览器打开 `http://localhost:1420` 即可看到主界面。

## 上手路径

第一次使用，建议按这个顺序：

1. **[模型配置](./快速上手/模型配置.md)** —— Agent 的所有能力都由大模型驱动，先添加一个可用的模型预设。
2. **[智能编码空间](./快速上手/智能编码空间.md)** —— 主工作空间：打开项目、配置工作空间模型、开始对话、管理会话。
3. **[IM 渠道](./快速上手/IM渠道.md)** —— 把 QQ / 微信 / 飞书等 IM 平台的消息接入 Agent。

之后可以读[会话与上下文](./进阶用法/03-会话与上下文.md)，了解分支、精简、checkpoint 的完整用法。

## 维护这份指南

指南内容就是本仓库 `guide/` 文件夹里的 markdown 文件：

- 新建 `.md` 文件或文件夹，目录自动出现对应条目（默认按名称排序；目录下放 `.order` 文件可强制指定子项顺序，每行一个条目名，`#` 开头为注释）。
- 图片放在文档旁边的 `assets/` 文件夹里，用相对路径引用。尺寸写法：`![说明](路径 =75% left)`，支持固定宽度 `=800x` 或百分比 `=75%`，对齐可选 `left` / `center` / `right`；也兼容 Typora 粘贴产生的原生 `<img>` 写法（zoom / width 均可解析）。
- 提示块用引用语法定义，首行写类型标记：`> [!TIP]`（类型可选 `NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION`，各带默认配色与图标），正文支持完整 markdown。颜色可自定义：`> [!NOTE #4f46e5]` 或 `> [!NOTE indigo]`（hex 或常用色名），还可以在颜色后追加自定义标题：`> [!NOTE indigo 自定义标题]`。
- 指南工作空间会随文件改动自动刷新目录。
