# v0.2.1 更新公告

本次更新涵盖自 v0.2.0 以来的全部改进，包含 190+ 次提交（另含 AgentDev 框架仓库同期 20+ 次提交）。

本轮更新有两条主叙事。其一是 **Coder 正式发布**：v0.2.0 亮相的无人值守编码身份走到正式形态，直接内嵌于编程小助手工作空间；随之一并首发的还有「领域 Feature」——整合工具、技能与使用纪律的能力组织新范式，以及一套设计上更加成熟稳健、以 Coder 落地验证的线程系统。其二是**性能**：针对大规模使用暴露的瓶颈，对轮询、列表与存储三条链路做了力度较大、覆盖较广的治理，实际成效显著。

- **Coder 正式发布**：内嵌编程小助手，按工单自主交付；调度能力经首个领域 Feature（`coder_shell`）组织呈现
- **领域 Feature 新范式**：把一个领域的工具、技能与使用纪律收编为一个自包含 Feature——解决 MCP 工具引入导致的上下文工具数量爆炸，与 CLI 工具缺乏监管控制的问题
- **性能**：消息轮询增量化（未变化零请求）、会话列表分页与条件刷新、会话文件紧凑序列化
- **远程访问（Beta）**：连接另一台机器上的 Claw，远程工作空间与会话进入本地工作台
- **访问保护**：可选的单密码认证，远程连接自动携带凭据
- **体验**：输入框常驻不重建、会话阅读位置语义锚点、滚动闪抖治理、Git 提交图复刻 VS Code 泳道渲染

## Coder 正式发布：内嵌编程小助手的自主编码身份

Coder 在本版本正式发布。它不是一个独立的工作空间，而是直接内嵌于编程小助手——同一个工作空间承载两个身份：用户交互式的编程会话照旧，Coder 则作为无人值守的自主编码身份，承接由调度面创建的工单，长任务持续推进直至交付，不需要人在场。

### 自主工单交付体

Coder 的系统提示词按交付纪律重写：收工以验证为准、验证从具体到宽泛、修根因不修表象、外科式精确修改、不镀金、授权边界内自主执行。交互式组件与探索分支一并摘除——无人值守场景下等待用户输入不再造成工单卡死，Coder 是单一职责的自主执行体。

### 领域 Feature：能力组织的新范式（首发）

Coder 的正式发布同步带来了一个新的能力组织范式——**领域 Feature**：把一个业务领域的工具、技能与使用纪律收编为一个自包含的 Feature，作为该领域的唯一操作面。它针对的是当前 Agent 生态的两个通病：

- **MCP 工具数量爆炸**：接入一个 MCP server，几十个工具全量灌进上下文——模型在大量无关工具间分心，提示词随之膨胀
- **CLI 工具缺乏监管**：让 Agent 在 shell 里直接敲命令行，能跑什么、以什么参数跑完全不受约束，既无法审计也不可控

领域 Feature 的解法是把「能做什么」收敛为**声明式的受限动词表**，调用语法走白名单（字面量参数、管道与重定向可用；命令替换、变量、通配、后台执行一律拒绝）——Agent 的每一步都被约束在声明过的能力面内；配套技能内嵌于 Feature 随装配注入，使用纪律与工具同源，不再散落在外。

首个落地的领域是 **Coder 调度**：`coder_shell` 工具与 `claw-coder-dispatch` 技能打包为一个领域 Feature，装配进编程小助手。对话中一句「派个 coder 去修」即可走完整的创建、派发、监视、收口流程，支持同批次并行派发、投递即返回（`--no-wait`）、超长输出自动落盘。这套范式不限于调度——任何 MCP / CLI 密集的领域都可以按此组织，后续将陆续迁移。

### 线程系统：成熟稳健的调度基座

线程（WorkThread）是 Coder 的承载模型，本版本完成了一轮设计与实现的整体加固，核心不变量由框架层强制保证：

- **身份归属**：线程身份以根会话为事实来源，工作目录不符或身份不符的会话无法加入线程，失败返回明确错误码而非静默错乱
- **归档即取消**：归档线程先中断运行中的调用再归档，运行中任务不会因归档变成孤儿；已归档线程拒绝新指令，取消归档可恢复看板
- **删除级联清理**：线程可直接删除，会话链、指令收件箱、看板等关联数据一并清理，不留悬挂记录
- **接力失败收敛**：会话接力（精简 / 摘要后的轮换）提交失败时显式中断并落结构化状态，不再悬挂；服务重启后线程状态完整恢复
- **派发就绪闸**：指令派发前自动唤起目标运行时——runtime 失联不再产生永久滞留的待处理指令

### 派遣闭环

- **CLI 一步派遣**：`claw sessions create` 创建会话、命名、拿到线程句柄一次完成，调度方无需创建后反查；`claw threads send --wait-started` 在同一次调用内确认回合真正开始（投递成功 ≠ 开始执行的闭环补齐）；`threads watch` 支持多线程监视、任一线程落定即返回，并可携带末轮结果
- Coder 会话创建必须显式指定工作目录，不再静默回退到默认目录

## 性能：大规模使用下的系统性提速

会话目录增长到近 2000 个 / 3GB+ 时，旧架构的问题集中暴露：每 3 秒一次的全量轮询（MB 级载荷）持续占据服务端单核，会话创建与激活请求排队数秒。本轮对轮询、列表与存储三条链路做了系统治理，是本次更新的重点之一：

- **消息轮询增量化**：轮询循环先探测消息版本号，未变化时零请求；有变化时按类型取增量（追加段 / 末条 / 重写）而非全量拉取，校验失败自动降级全量重建。多会话挂机场景下，网络与服务端开销大幅下降
- **会话列表分页与条件刷新**：列表按需分页加载（滚动到底自动追加），传输只携带界面所需字段；索引版本未变时短路返回空响应，跳过数千条会话的投影与序列化
- **会话文件紧凑序列化（v2.1）**：序列化去掉缩进空白（历史数据中约占总体积 21%），读取端无需兼容分支；附带迁移脚本（逐文件备份 + 深等价校验 + 原子重写），支持试运行与按 agent 迁移

治理后的实际成效：服务端不再被轮询占满单核，会话激活从排队数秒恢复到亚秒级响应，常态轮询在无变化时近乎零开销，会话文件磁盘占用约降低两成。

## 远程访问（Beta）：连接另一台机器上的 Claw

远程访问体系本版本首次亮相，当前为 **Beta** 阶段：连接、浏览与常用会话操作的主链路已经跑通，整体仍在持续打磨，部分场景可能不稳定，不建议在关键场合依赖。欢迎试用与反馈。

### 连接管理：隧道与直连

- **SSH 隧道模式**：填写 SSH 目标即可，隧道的建立、保活与回收全程自动托管，连接失败时透出远端 stderr 诊断
- **HTTPS 直连模式**：面向只有 HTTPS 反代可达的部署形态（内网穿透、容器托管）——无需 SSH 入站，直接以远程地址连接，不启动任何本地端口与 SSH 进程
- 每条连接有独立的握手探测与健康状态机，侧栏分组实时显示连接状态徽标（正常 / 降级 / 断开），断开时分组保留不伪装
- 远程实例开启访问保护时，在连接配置中填入访问密码即可自动登录，cookie 失效自动续期，无凭据与密码错误分别给出明确提示

### 远程工作空间与会话

- 远程工作空间目录自动聚合进侧栏，按「主机别名：项目名」分组，与本地项目并排呈现——不产生独立的「远程」层级；远程运行中的会话与本地会话汇合成统一条目流，选中、切换、右键菜单同构
- 远程会话的消息 / 工具 / 钩子 / 概览经只读通道透传渲染，输入区显示明确的禁用提示
- 在此之上，远程历史会话的打开与管理、新建对话、发送消息、分支与精简（Trim / Summary / Compact）、重启关闭等会话操作链路已打通，并按远程端实际能力门控（旧版本远程端不支持的操作优雅隐藏，而不是点了报错）
- 交互页面（Generative UI）、会话控制、日志、MCP 信息、Git 源代码管理面板已完成远程适配，跟随远程会话工作

## 访问保护与安全

- **单密码访问保护**（可选）：在设置的「访问保护」页配置后，浏览器访问工作台与全部控制 API 都需要先登录；密码以服务端哈希形式保存，不存明文。适合工作台需要暴露给局域网 / 反向代理的场景
- **登录会话策略**：闲置 3 天过期、自登录起最长 7 天；会话持久化落盘，服务重启后保持登录；修改密码或关闭保护即作废全部会话
- 远程实例的凭据只保存在本地连接配置中，连接管理界面仅回显「已配置」状态，密码明文不出服务进程
- **框架侧加固**：ViewerWorker 默认只绑定本机回环地址，不再暴露给外部网络

## 模型能力

- **模型热切换官方链路**：具名默认预设与切换回执语义落地，热切换状态由 agent 自持
- **模型预设收藏**：常用预设可星标，星标预设优先排列
- **逐步轮换模型**：新增「每步轮换模型」能力（默认关闭），在会话控制面板开启与配置——由 Agent Studio 制造、验证后装配进编程小助手，是「Studio 制造 → 工作台消费」链路的首次完整示范
- **用量分段归因**：一次调用内轮换过多个模型时，token 消耗按各模型分别记账，不再全记到调用结束时所在的模型
- **镜像任务关闭隐性思考**：摘要、标题、回顾等后台任务对 Anthropic 协议显式关闭思考，不再为辅助任务消耗 reasoning token
- **框架侧**：流式解析识别 OpenRouter 等网关风格的 reasoning 扩展字段

## 界面与交互

### 输入区与导航

- **输入框常驻**：输入区 DOM 常驻，模式翻转（普通输入 / 选择卡片 / 语音等）改为属性级更新，不再销毁重建——焦点、输入法状态、光标位置在各类切换间自然保留，此前一类「输入框丢焦」问题的根因就此消除
- **导航反馈**：新建 / 打开会话即时切入加载态直到内容落地，不再出现视图悬空；侧栏乐观条目稳定，不再「先消失后重现」；从工作空间首页打开会话不再黑屏
- **会话阅读位置语义锚点**：阅读位置按消息行锚点记录与恢复，切换标签页、切换会话、界面重渲染后视口仍落在原来的消息行上——不再因上方内容高度变化而漂移
- 线程输入反馈区分「已投递」与「已暂存」两种状态

### 滚动治理

- 拖动分割条与窗口缩放时的滚动闪抖、滚动条拖动松手后的视口跳动、长内容块快速上滚时的视口晃动、过程模式切换的首帧跳动——一批滚动协调缺陷集中修复

### 面板与视觉

- **Git 提交历史图形**：复刻 VS Code 的泳道渲染——槽位逐行传递、merge 双环、HEAD 空心环、行内圆弧横移；展开提交详情等流式内容不再导致下方泳道错位
- **会话控制面板**：自动接续、上下文保护与模型轮转控制集中入驻，一处管理会话级行为
- **交互页面组件**：新增 Chart 与 Sparkline 图表组件，Agent 可直接产出可视化图表
- **亮色主题配色细化**：代码高亮与 markdown 样式随主题正确切换
- 答题卡片升级为玻璃卡片样式；ask_user_choice 提交闪回与运行时长胶囊残留修复
- 左上角品牌名片改为点击展开；「跟随最新」按钮动态锚定输入卡顶边；侧栏宽度拖动接入最小宽度约束，窄屏自动收起抽屉
- 录音提示音即时反馈，消除点击后的声音延迟
- 页面标题由「Agent 调试器」改为「Agent 工作台」

## 问题修复

以下均为 v0.2.0 及更早版本中存在的问题：

### 会话与消息

- **新建会话首条消息延迟显示**：轮询对账按序号前进即取数，不再等下一轮全量
- **归档 / 删除会话不再复活已停止的后继会话**
- 关闭 Agent 时，同项目下兄弟会话的宿主寻址补齐，不再误投
- 侧栏选中工作空间时不再误高亮全部运行会话
- 摘要生成超时改为单次尝试级期限，单次超时不再侵占整体重试预算

### 远程连接（Beta）

- 远程会话发送消息 401、远程渲染模板加载失败、连接启用开关切换报 400、已保存密码不回显掩码、断线判定慢断快收——Beta 阶段首批使用反馈集中修复
- 远程会话的调用运行状态并入本地同一条轮询与清理链路，状态展示不再残留

### 其他

- coder 的模型预设配置正确持久化，不再丢失
- ACP 停止操作在会话键漂移的防御态下仍能正确定位目标
- Agent Studio 的技能注入恢复，dev agent 重新获得工作流技能
- CLI 控制面在开启访问保护后不再被认证拦截
- 反向代理下 CSRF 同源校验误拦写请求
- 模型调用因网络等待挂起时监听器累积的告警（框架侧修复）
- edit 工具的归一化匹配扩展至 Unicode 空白与零宽字符（框架侧修复）
