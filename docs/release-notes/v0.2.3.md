# v0.2.3 更新公告

本次更新涵盖自 v0.2.2 以来的全部改进，包含 150+ 次提交。

**这次更新，可以先试三件事：让 Memo 记下一件事、在文件夹里右键开启编程对话，以及用滑动条精简一次长会话。**

v0.2.3 新增 Memo 智能备忘录，把随手记、便签浏览和定时提醒放进一个工作空间；桌面版增加目录右键入口、通知直达和关窗选择，语音输入支持边说边出字。对于长时间使用编程小助手的用户，Coder 有了独立的任务入口与更灵活的自动接续，手动精简更直观，模型登录、会话切换和历史阅读中的一批问题也得到修复。

- **Memo 智能备忘录**：对话记笔记、首页便签墙、就地编辑，支持单次与每日 / 每周 / 每月提醒
- **Coder 独立工作空间**：自主编码任务集中呈现，沿用对话调度、ACP 与 CLI 创建方式；上下文接续可选自适应、纯精简或纯摘要
- **统一精简页面**：按轮次与按比例两种模式，时间轴上直接调整保留起点，摘要与归档按需组合
- **流式语音输入**：接入兼容的流式识别服务后，边说边出字，并保护手动编辑过的草稿
- **桌面体验**：Windows 目录右键打开 / 创建会话，关窗时选择托盘或退出，通知点击直达对应会话
- **模型配置与登录**：Codex 浏览器授权、订阅与自定义模型分区配置，运行中会话同步更新凭证
- **输出风格与使用帮助**：会话内选择自定义表达规范，逐轮确认；直接向编程小助手询问工作台用法
- **Agent Studio**：以 Feature 为中心组织开发与验证，会话可以关联多个 Feature

## Memo 智能备忘录：随聊随记，到点提醒

新增 **Memo 智能备忘录**工作空间，把对话与笔记、提醒放在一起。打开首页即可查看最近笔记与提醒，也可以在底部快记输入框直接说一句，让 Memo 帮你记录。

### 笔记与便签墙

- **对话记笔记**：通过自然语言创建、查找和修改笔记，记录结果保存在 Memo 中，首页可以直接浏览
- **总览与分类阅读**：首页聚合笔记与提醒，分节标题可进入对应列表；笔记以便签墙呈现，点击后在页内阅读
- **就地编辑**：双击便签内容进入编辑态，在原位置完成修改，减少阅读与编辑之间的切换
- **连续对话**：平时打开即可接着上次聊，聊长了自动整理上下文继续；选择「新建对话」会归档旧对话并重新开始，已保存的笔记与提醒继续保留

### 定时提醒

在对话中说「明天九点提醒我开会」即可登记提醒，支持**单次、每日、每周和每月**，每周提醒可指定多个星期几。

- **简单事项直接提醒**：到点弹出登记的文案，无需再调用模型生成
- **需要处理的事项唤醒 Memo**：对于需要查看、思考或生成内容的安排，到点唤醒当前对话继续处理
- **列表管理**：首页按时间分组展示提醒，可以标记完成或删除；对话中也能查询与管理
- **重启后恢复**：服务启动后恢复提醒计时，错过预定时间的提醒会补触发并标注迟到；新建对话与上下文接续不会清除提醒

**提醒需要工作台保持运行**：桌面版可最小化到托盘，Memo 会继续计时；退出程序、关机或手动停止 Memo 后，到点不会即时提醒，重新启动后会补触发。接收通知还需保持工作台在线，并允许 Memo 与系统通知。当前支持工作台通知，暂不支持离线通知补投或 IM 渠道推送。

## Coder：独立工作空间与自适应接续

Coder 从编程小助手内的编码身份升格为**独立工作空间**。用户交互式编程仍在编程小助手中进行，自主编码工单则集中在 Coder 中查看，模型与 Feature 配置分别管理。历史 Coder 会话在启动时自动迁入新的工作空间。

- **调度方式不变**：在编程小助手中派遣 Coder，或通过 ACP / `claw threads` 创建工单；Coder 不提供用户手动新建普通对话的入口
- **按需显示入口**：存在运行中的 Coder 会话或正在接续的任务时，左侧显示 Coder 入口；仅有历史线程时不常驻占位，也可在工作空间设置中调整可见性
- **接续时仍能看、能补充**：整理上下文期间可以继续阅读上一段对话，也能补充要求；输入会暂存，待新会话就绪后送达
- **归档随时可用**：运行中或接续中的任务均可归档，归档会中断当前执行；已归档线程不再接收新指令

### 三种上下文接续策略

在智能编码空间设置的「Coder 策略」页，可以选择下一次接续使用的策略，保存后无需重启。

| 策略 | 适用方式 |
|---|---|
| **自适应（默认）** | 先试算精简后的体积；释放充分时直接精简，释放一般时追加摘要，释放不足时改用纯摘要 |
| **纯精简** | 保留对话文本，折叠较早的工具活动，并保留最近的工具调用细节 |
| **纯摘要** | 将历史整理为摘要，再由新会话接续 |

自适应策略让工具输出占比高的任务优先采用无需生成摘要的精简；当对话本身占据大量上下文时，再使用摘要释放空间。这一策略本版本先用于 Coder，其他工作空间的自动接续方式保持原样。

## 会话精简：时间轴与比例控制

会话右键菜单中的「仅精简」与「精简并归档」现在打开同一套精简页面。左侧时间轴提供上下文，右侧配置精简方式，保留边界与预计释放量可以一起看清。

- **按轮次**：沿用逐轮选择方式，支持非连续选择与「精简到此处」
- **按比例**：拖动滑动条、输入比例，或在时间轴上指定「从此保留」，切点与读数即时联动
- **安全切点**：优先在轮次之间切分；单轮过大时允许切入轮内，同时保持工具调用与结果配对完整，并保留有效对话
- **选项集中**：是否生成摘要、是否归档原会话、保留最近技能调用，在同一页面设置；提交后创建并切换到后继会话

比例读数按字符量估算，**不是精确的 token 预算，生成的摘要另计**。比例精简主要通过折叠早期工具活动释放空间，对话文本仍按既有规则保留。连接旧版远程服务时，按轮次模式继续可用，按比例模式会提示需要升级远程端。

## 流式语音输入：边说边出字

语音模型配置新增接口格式选择，支持 Chat、Audio Transcriptions 与流式识别三种接入形式。

- **实时回显**：选择流式识别后，录音过程中识别文字持续进入输入框，无需等录音结束再查看整段结果
- **保护手动编辑**：未编辑的识别段可随新结果修正；用户开始手动修改后，后续文字改为在光标处增量追加，避免整段识别结果覆盖用户修改
- **也能连接工作台所在机器的识别服务**：从另一台设备打开工作台时，仍可使用部署在 Claw 所在机器上的语音识别服务

流式模式当前适配 **Qwen-ASR WebSocket 协议**，需要配置兼容的服务；其他语音服务可继续使用非流式接口。

## 桌面体验与通知

### Windows 目录右键入口

安装桌面版后，在资源管理器的目录空白处右键，可以选择：

- **在编程小助手中打开**：打开工作台并定位到当前目录
- **在编程小助手中创建会话**：直接在当前目录新建编程对话

应用尚未运行时自动启动，已经运行时激活已有窗口并完成跳转。

### 关窗选择与通知直达

- **关窗前确认**：点击关闭按钮后，可选择「最小化到托盘」或「退出程序」，按 Esc 取消；托盘模式继续运行服务，退出程序则结束桌面版托管的服务
- **通知点击定位**：Windows 原生通知支持激活工作台并打开对应会话，点击通知本体与操作按钮行为一致
- **前台轻提示，后台保留提醒**：任务完成和定时提醒在页面位于前台时使用普通通知，切到后台后使用持续显示、等待处理的通知；需要选择答案的提示仍使用普通通知
- **通知开关各归其位**：编程小助手与 Coder 的完成通知在智能编码空间设置中调整，Memo 的到点提醒在 Memo 设置中调整；全局设置可集中查看各工作空间的通知权限
- **同一事件只提醒一次**：修复完成通知和提醒重复弹出的问题

## 模型配置与登录

### 登录与选模型更顺手

在「设置 → 模型配置」中，可以从总览进入 **Codex 订阅、OpenCode 订阅或自定义模型**，按自己的接入方式完成配置。

- **Codex 浏览器授权**：点击登录后在 Claw 所在机器的系统浏览器中完成 OpenAI 授权，自动完成本机回调，无需手动复制授权结果。远程使用工作台时，仍可选择设备码，在其他设备上授权
- **订阅模型直接添加**：登录配置与模型列表分开呈现，目录中的模型可直接添加；OpenCode 密钥输入后自动保存，切换页面不再丢失
- **模型列表按来源查找**：配置页与会话内切换模型时，按来源分区，减少在长列表里寻找模型的负担
- **主 / 次模型分别设档位**：工作空间的两个模型槽位可以分别保存思考强度，可选档位随供应商能力变化

### 长时间使用，少一些登录中断

- **Codex 登录更稳定**：修复多个会话同时刷新登录状态可能导致凭证失效的问题，并在临近过期时提前刷新
- **重新登录后无需重开对话**：重新登录、替换 API key 或修改连接配置后，已有会话同步更新凭证，保留当前思考强度
- **OpenCode 旧配置也能续用**：修复旧 Go / Zen 预设重新登录后仍使用过期密钥，以及 Go 模型提示缺少会话标识的问题

### 等待与报错更清楚

- **无响应时及时结束等待**：普通对话默认首段等待上限为 120 秒，开始输出后连续 60 秒没有新数据则中断；持续输出不受总时长限制。摘要生成保留较长的处理时间
- **重试过程可见**：状态栏说明正在等待重试，连续同类失败合并展示，避免错误消息反复刷屏；刷新页面后也保持一致的呈现

## 让回复更合心意，也让工作台更容易上手

### 会话级输出风格

希望 Agent 的回复更简洁，或始终按团队约定组织说明？现在可以把这些要求写成 Markdown 风格文件，放入项目目录的 `.agentdev/output-style/`，在会话控制面板中选择，让后续回复遵循同一套表达规范。

- **会话独立选择**：风格只作用于当前会话，同一会话恢复时保留选择，新会话从未选择开始
- **逐轮确认**：启用后要求 Agent 在每次最终回复前通过确认签名；漏签会提示补签，为表达规范增加显式检查，但不等同于对内容质量的自动验证
- **随时切换或清除**：无需修改全局系统提示词，也不会让同目录下的其他会话自动继承

### 写作与设计协作

- **工程素养提醒**：写出成规模文档后，提醒 Agent 从读者视角检查成品；跨多轮修改同一文档时，重新判断当前是在共同讨论，还是已经进入交付阶段，先审视全文结构再局部修改
- **设计拷问技能**：内嵌 `grill-me`，可用连续追问梳理计划、决策与设计中的关键假设
- **工作台使用帮助**：内置 `agentdevclaw-help`，可以直接询问模型、MCP、技能、会话管理与故障排查，也支持从其他编码 Agent 迁移时的概念对照
- **指南补全**：更新模型配置与上下文说明，新增 MCP 配置、技能配置和会话管理篇，调整阅读顺序并补充图示

## Agent Studio：开发的能力更容易找到

在 Agent Studio 中开发 Feature（能力插件）时，现在可以直接围绕每个 Feature 查看进展、验证结果与相关对话，不必再先建一个「项目」来管理。

- **一项能力，一处查看**：首页以 Feature 展示开发状态、验证记录与已打包版本
- **相关对话自动归类**：创建或登记 Feature 后，当前对话自动关联；一次对话开发多个 Feature，可以从每个 Feature 下找到这段对话
- **选好目录即可开始**：取消独立的初始化步骤，同一目录可以开发多个 Feature
- **升级自动整理旧记录**：原有项目中的 Feature 与历史会话自动迁入新视图
- **插件详情更完整**：浏览仓库时，可以查看插件声明的能力、依赖与运行要求

## 技能配置：公共目录与项目目录一起用

如果已经在全局或工作空间配置了公共技能目录，现在可以继续为某个项目添加专用目录，**公共技能和项目技能会同时生效**，相同目录自动去重。

设置页会单独列出继承的目录并标明来源，输入框只编辑当前层添加的目录。配置项目技能时，更容易看清哪些来自公共设置、哪些只对当前项目生效。

## 日常使用：阅读更方便，挂机更轻

- **消息有了时间分隔线**：隔一段时间回来继续聊，更容易分辨每次输入的时间
- **代码块一键复制**：回复中的 Markdown 代码块可直接复制，取用命令和代码更方便
- **右侧面板直接排序**：长按面板图标即可拖动调整顺序，把常用面板放到顺手的位置
- **上下文保护开关更好找**：超阈值自动打断开关移至顶栏用量条旁；加载会话时，用量读数与「显示过程」按钮保持可见。切换模型仍从输入框工具栏操作
- **查看工具修正前后内容**：工具执行时若修正了参数或调用名，卡片会标注「已修改」，展开即可对照原始调用
- **引用历史对话更克制**：Agent 可翻页查找历史会话、按需读取某一轮；超长单轮会明确标注省略内容，减少一次塞入大量无关历史的情况
- **Git 面板更流畅**：大量文件更改与长提交历史下，减少反复刷新造成的卡顿
- **多会话挂机更省流量**：空闲页面、远程目录和线程列表减少无变化时的重复传输；后台任务数仍及时更新，重新打开面板即可看到已有输出
- **减少后台动画负担**：全页光晕改为静态效果，长时间挂着工作台时少做无用绘制

## 其他调整与升级提示

- **LSP 按需安装**：代码语义分析插件改为默认不挂载，需要时可在挂载管理中添加
- **暂停逐步模型轮转**：编程小助手移除自动逐步轮换模型的入口，手动切换模型照常使用
- **Coder 运行数量上限**：可在「Coder 策略」中限制运行实例数，控制资源占用；本版本按运行实例而非未归档任务计数，自动接续时的替换实例不额外占用名额
- **结束 Coder 任务请用归档**：归档会中断执行并保留任务记录；使用外部脚本的用户，需将旧的线程 `close` 操作改为归档
- **Coder 与 Memo 自动接续**：这两个工作空间的对话由系统自动管理上下文，不提供通用的手动精简 slash 命令

## 问题修复

### 输入与会话切换

- 切换会话后，不再残留上一个会话的排队消息气泡
- 选好的 slash 命令胶囊在切走再回来后仍保留
- 修复选择题、普通输入、语音与回车提交相互干扰的问题
- Agent 运行中也可回退消息，成功后立即更新对话，失败时明确提示原因

### 长会话与任务接续

- 修复阅读历史消息时因输入方式切换而突然跳顶的问题
- 修复持续输出时出现大片空白消息行的问题
- 精简页关闭或切换目标后，不再被旧会话的迟到预览覆盖
- 加固自动接续时的保存与恢复，减少末尾消息遗漏、保存成功却误报失败的问题
- 接续期间补充的输入不会误发给旧会话或其他会话；失败与服务重启后的任务状态更清楚
- 达到上下文保护阈值时，等待当前工具返回结果再打断；切换模型后，保护阈值及时跟随新模型

### 桌面与升级

- 修复桌面通知不弹出、重复弹出和点击后未打开目标会话的问题
- 修复桌面安装包缺少必要组件导致新旧会话均无法启动的问题
- 覆盖升级后，指南不再混入旧版已删除或改名的文章
- 会话启动失败时保留诊断日志，便于报告和排查问题
