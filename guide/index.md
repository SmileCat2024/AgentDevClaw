# AgentDevClaw 使用指南

AgentDevClaw 是一个以 Agent 为中心的本地工作台。它把几类 AI 工作空间装在一起：写代码的「智能编码空间」、接入 IM 消息的「IM 渠道」，以及开发和装配能力包的「Agent Studio」。在每个工作空间里，Agent 在你指定的项目目录中读代码、改代码、执行命令，直到把事情做完。

## 先认识四个概念

- **工作空间** —— 功能单元，每个聚焦一类事，左侧列表就是入口。
- **会话** —— 一次具体的交互过程，绑定一个项目目录，可以分支、精简、总结管理。
- **Feature** —— 能力包，这是理解 AgentDevClaw 的关键：你在对话里用到的每一个工具，背后都是一个 Feature。
- **Agent** —— Feature 的装配体，把一组 Feature 组合成完整的智能体。

Feature 参数按**全局 → 工作空间 → 目录**三个层级继承，越具体的层级越优先。概念模型与配置层级的完整说明见[基础概念](./基础概念.md)。

## 启动

```bash
npm install
npm start
```

`npm start` 会自动完成本地 Feature 编译再启动服务。浏览器打开 `http://127.0.0.1:1420` 即可看到主界面。

## 上手路径

第一次使用，建议按这个顺序：

1. **[模型配置](./快速上手/模型配置.md)** —— Agent 的所有能力都由大模型驱动，先添加一个可用的模型预设。
2. **[智能编码空间](./快速上手/智能编码空间.md)** —— 主工作空间：打开项目、配置工作空间模型、开始对话、管理会话。
3. **[IM 渠道](./快速上手/IM渠道.md)** —— 把 QQ / 微信 / 飞书等 IM 平台的消息接入 Agent。

之后可以读[会话与上下文](./进阶用法/会话与上下文.md)，了解分支、总结、精简、回退的完整用法。
