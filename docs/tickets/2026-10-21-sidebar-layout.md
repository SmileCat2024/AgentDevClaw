# 左栏应用与文件夹可整理布局

## 用户已确认

- 保留纵向左栏；工作空间是应用，系统空间和工具与效率是文件夹；工作群分类退役，群聊后台代码不在本次删除范围。
- 长按拖动排序：文件夹顺序、文件夹内应用顺序；应用可跨现有文件夹移动，也可移至顶层，顶层应用与文件夹可混排。
- 短按仍打开应用/切换折叠。拖动松手保存；文件夹标题触发放入，描边包住整个文件夹标题与内容；应用区和行间空隙表示排序，左缘表示顶层排序。同一时刻只显示一个落点，不显示底部拖动操作说明；保存状态和错误提示不占列表布局，相同落点不重复改写高亮。
- 布局与各文件夹展开/折叠保存在 Claw 用户数据，同一 Claw 的浏览器和桌面端共用；刷新和服务重启保持。
- 隐藏的应用保留位置，恢复时回原位。新应用按默认分类追加，不打乱已整理位置。
- 项目目录/运行中会话保持原行为与拖动引用能力。不新增创建/重命名/删除文件夹。
