# 通知设置

让 Agent 跑着任务、你去干别的，完成后它会叫你。AgentDevClaw 的系统通知按「你当时在哪里」区分提醒方式：正看着的对话不打扰，切到别处或把窗口最小化时才提醒。

## 在哪里配置

打开编程小助手工作空间卡片上的「工作空间设置」，进入「通知」页签。Coder 的通知项也集中在这里配置。

## 提醒场景与默认值

**任务完成时**（运行结束后提醒）按你当时所在的位置分三档，各自独立设置：

| 你在哪里 | 默认 |
| --- | --- |
| 在当前对话 | 不通知（结果已经在屏幕上） |
| 在别的对话或页面 | 短通知 |
| Claw 在后台（最小化或切到其他应用） | 常驻通知 |

**需要你决策时**——对话中出现选择题、等待你选择——默认常驻通知；**Coder 任务完成时**（线程轮次完成或失败）默认常驻通知。

## 三种提醒方式

- **不通知**：完全安静；
- **短通知**：系统通知轻提示，弹出后自动收起；
- **常驻通知**：停在屏幕上直到你处理，点击通知可直接跳回对应会话。

每个场景都有总开关：关闭即整组静音，重新开启时按建议档恢复默认。
