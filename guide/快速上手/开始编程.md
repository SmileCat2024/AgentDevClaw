# 开始编程

智能编码空间是面向真实编码任务的编程工作空间：您打开一个本地项目目录，用自然语言描述需求，Agent 就在该项目里读代码、改代码、跑命令，直到任务完成。

### 1.打开一个项目

1. 在左侧工作空间列表点击「智能编码空间」。
2. 首次使用会看到欢迎页，点击「打开项目」，选择一个本地文件夹作为工作目录。

会话与项目目录绑定：Agent 的所有文件读写和命令执行都在这个目录下进行，不会越界。多个项目通过顶部的项目下拉随时切换。

### 2.配置工作空间模型

在「工作空间设置」的「模型配置」标签页中，可以为编程小助手设置主模型和备选模型，Coder、系统管理分别设置单个模型；不指定则跟随全局默认。完整说明见[模型配置](./模型配置.md)。

![按角色指定模型](./assets/智能编码空间模型配置.png =75% left)

### 3.主副模型切换

项目条上的模型标签显示当前主模型。配置了备选模型后，点击标签即可在主副模型之间一键切换，立即生效。

![点击切换主副模型](./assets/主副模型切换.png =75% left)

### 4.开始一段对话

点击「新对话」，直接描述您想做的事，例如「这个报错是什么原因」「给导出功能加一个确认弹窗」。Agent 具备完整工具链，会自己完成检索、编码、验证：

- **Shell**：执行命令、跑测试
- **LSP**：跳转定义、查引用等代码导航（官方可选插件）
- **Web 搜索**：查文档、查报错
- **MCP**：连接外部工具
- **浏览器自动化**：打开网页、截图、自动化操作（官方可选插件）

LSP 与浏览器自动化默认未装配，在「工作空间设置 → Feature 设置」的 Feature 商店中装配后，对新会话生效。

任务执行过程中您可以随时补充信息或中断；会话标题会由 AI 自动生成。

需要参考之前某段对话时，点击输入框的「+」选择「会话」（或把左侧列表中的会话直接拖进输入框）即可引用历史会话，Agent 会按需读取其中的内容。用法详见[跨对话记忆](../基础用法/跨对话记忆.md)。

### 5.管理会话

会话列表右侧的「⋯」菜单（或右键）提供：

- **总结历史**：把整段对话压缩成结构化摘要
- **精简历史**：裁剪早期轮次，释放上下文空间
- **创建分支**：从指定轮次衍生新会话，原会话保留
- **归档 / 重命名 / 删除**：整理会话列表

同一项目的会话按项目归组展示，旧会话随时「打开对话」继续。

> 左侧列表中还能看到同一工作空间下的「Coder」入口：那是无人值守的自主编码线程，由调度面（ACP / 线程命令）创建并推进，您可以在其中查看执行进度，但不能直接新建。

### 6.右侧面板

对话区右侧的面板栏提供多项辅助功能，常用的有：

- **计划**：Agent 的任务清单。长任务执行中，Agent 会自己维护一张待办列表，在这里实时呈现。每个任务旁有「执行到此处」按钮，点击后 Agent 会持续推进直到完成该任务——作用类似其他 Agent 的 Goal 机制：设定一个目标点，让 Agent 自主奔着它执行，无需逐步催促。
- **后台任务**：构建、测试这类长命令转入后台后，在这里查看输出与状态；「立即汇报」把进度即刻送进对话，「打断」随时中止。详见[后台任务](../新功能/后台任务.md)。
- **功能**：查看当前会话装配了哪些功能、每个功能提供的工具与运行状态；某个工具不见时，先来这里排查它是否挂载。
- **交互页面**：图表、表格等可视化内容的展示区。想要更直观的呈现时，直接对 Agent 说「画个图表放到交互页面」，Agent 会生成可交互的页面显示在这里。

面板栏底部的「⋯」按钮打开「自定义面板」：开关任一面板的显示、拖拽调整顺序；边栏图标本身也支持长按后拖动排序。

### 7.工作空间设置

点击工作空间卡片右上角的「工作空间设置」，可以调整进程模式与 Feature 参数：

- **进程模式**：选择新会话的进程运行方式。「按项目共享进程」让同一项目下的会话共享进程，内存占用更低、启动更快；「全局共享进程」让所有项目的主会话共享一个进程，内存占用最低，但进程异常会中断所有项目中的运行会话；「独立进程」让每个会话独占进程，完全隔离、最稳定。已运行会话会在下次重启后使用所选模式。

![进程模式](./assets/智能编码空间进程模式.png =75% left)

- **Feature 设置**：按身份分别配置 Feature 参数。「编程小助手 Feature 配置」对所有项目目录生效，目录级配置可以覆盖；「Coder Feature 配置」仅包含其实际挂载的 Feature，Coder 层覆盖同名全局配置项。各身份配置页内嵌 Feature 商店，可装配官方可选插件（LSP、浏览器自动化）与已安装的扩展，装配对新会话生效。

![按身份的 Feature 配置层](./assets/编程小助手和coder的配置.png =75% left)

![在工作空间设置中从 Feature 商店添加扩展](./assets/工作空间Feature挂载.png =85% left)
