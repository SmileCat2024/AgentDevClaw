# 上下文接续与精简

对话越聊越长，上下文接近模型上限时，AgentDevClaw 会自动接手：编程小助手的新对话默认开启「自动接续」，过界后自动接力到新会话继续工作。你也可以随时手动精简或总结，主动控制处理的时机。

## 自动接续：新对话的默认行为

会话上方的状态条显示上下文用量。用量超过阈值时，自动接续会等手头的工具调用落地后打断当前轮，自动执行一次线程接力：顶栏出现「上下文接力中…」，接力完成后工作在新会话里继续。

从你的视角看，对话没有中断：会话列表里仍是这一行对话，接续前各代的完整记录收进了它的「历史」入口，随时可以回看。

## 盾牌图标：守卫三档

状态条进度旁的盾牌图标控制过界时的行为，点击循环切换：

| 档位 | 行为 |
| --- | --- |
| **自动接续**（默认） | 过界后自动打断并接力到新会话 |
| **自动打断** | 过界后拦下一次输入，提醒先处理上下文；继续输入即视为批准，本次越界不再拦截 |
| **关闭** | 不再自动处理，上下文持续增长直至模型窗口上限 |

档位随会话记忆：接续、分支产生的新会话沿用之前的设置。

## 接续策略

右侧「会话控制」面板的「上下文接续」区，可以选择接力时处理上下文的方式。策略仅对当前会话生效，改动对下一次接力即时生效：

- **自适应**（默认）：先精简，压缩不足时逐级升级为摘要；
- **精简优先**：折叠工具活动，保留对话文本与最近五批工具调用，无额外模型开销；
- **摘要优先**：把整个会话浓缩为一份摘要，上下文最小。

选中「精简优先」时，下方会出现「附带摘要」开关：裁剪结果末尾再附一份摘要，接续后不必重读调查过程，代价是每次接力多一次模型调用。选中「摘要优先」时会出现「附带最近用户输入」开关：以提醒块附上你最近几条输入的原文，避免摘要丢掉方向性要求。两个开关都只对当前会话生效。

状态条会同时显示当前档位与策略，例如「自动接续 · 自适应」。

> [!NOTE] 接力失败不会静默丢失
> 线程接力偶尔可能失败（如存储异常）。失败时不会有自动重试；回到会话再发送一条消息，下一次过界时会再次尝试接续。

## 手动精简与总结

自动接续是过界时的兜底；想在特定时机主动处理——比如一个阶段刚结束、上下文还远没到阈值——可以手动操作。在会话列表中右键目标会话（或点「⋯」菜单），选择「精简历史」或「总结历史」：

| 操作 | 做什么 | 适合 |
| --- | --- | --- |
| **精简历史** | 裁掉较早的部分轮次，保留后续对话原文 | 绝大多数场景；近期细节仍重要时尤其合适 |
| **总结历史** | 将整段历史压缩为结构化摘要，并基于摘要继续 | 探索阶段结束，后续只需掌握结论与当前状态 |

大多数情况下，选择「精简历史」并直接确认即可。精简面板默认按轮次选择可精简内容；需要保留特定轮次时取消对应勾选，或切换到「按比例」模式调整保留范围——滑杆与鼠标滚轮均可调节，并实时预览保留区与精简区。

![按比例精简时使用滑杆或滚轮调整保留比例](./assets/精简面板按比例调整.mp4 autoplay loop muted =75%)

提交时还可组合其他选项：「精简并生成摘要」在腾出空间的同时保留一份早期结论；「精简并归档」将原会话归档，在新会话继续工作。
