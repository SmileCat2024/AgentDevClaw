# v0.2.2 更新公告

本次更新涵盖自 v0.2.1 以来的全部改进，包含 230+ 次提交（另含 AgentDev 框架仓库同期 40+ 次提交）。

本轮的两条主叙事。其一是**工作台走向桌面**：Windows 一键安装包就位，随包自带完整服务运行时，安装即用；关闭窗口驻留系统托盘、服务继续运行，重复启动只激活已有实例，本机已有运行中的服务则直接附着复用。其二是**能力的自助装配**：Feature 商店与挂载管理全面改版，官方插件与用户 Feature 包进入同一货架，工作台内一键挂载、即装即用，服役两代的旧 Feature 仓库工作空间就此退役。

伴随而来的是一组直面日常工作的新能力：后台任务面板让长命令不再霸占前台，轮次挂起语义让「派出去、到点回来」形成完整闭环；跨对话记忆把历史会话变成可引用的资产；工具调用过程有了统一的分层卡片，各类工具陆续换上专属展示样式；Agent Studio 重做为以项目为中心的制造端；时间感知让 Agent 对「现在几点、上下文是否过时」有稳定把握。消息链路底层升级为服务端事件推送（SSE），变化即时到达浏览器。执行控制同步做了减法——「自动继续」与「断点」两个错位的控制整合为任务项上一处清晰的「执行到此处」。

- **桌面安装包（Windows）**：NSIS 一键安装，随包自带服务运行时；关窗驻留托盘服务不停，重复启动只激活已有实例
- **Feature 商店与挂载管理**：官方可选插件与用户 Feature 包合并货架，工作台内一键挂载/卸载；装配与配置同源，旧 Feature 仓库工作空间退役
- **后台任务面板与轮次挂起**：长命令转后台托管，终端式卡片按节奏汇报；派出后台任务后 Agent 如实进入「挂起等待」而非假报完成，到点自动唤醒
- **工具过程呈现重做**：工具调用有了统一的分层卡片，后台任务、读图、网页抓取各有专属样式；长内容默认收起，展开过的状态会被记住
- **跨对话记忆（Beta）**：输入框引用历史会话（「+」菜单 / 拖拽），Agent 按需读取其中上下文
- **Agent Studio 工作空间重做**：以项目为中心组织开发，自动实测验选可用的开发工具链，Feature 仓库管理并入，会话按项目归类
- **时间感知**：Agent 周期性获知当前时间；隔了很久再回来，不再代入过时的上下文假设
- **指南工作空间**：内置使用指南，左目录右正文阅读器，随版本持续更新
- **消息实时推送（SSE）**：会话事件由服务端主动推送浏览器，与轮询灰度并行
- **执行到此处**：取代「自动继续」开关与单项断点，任务项上的单一执行控制
- **领域工具扩充**：playwright_shell（浏览器取证与受控页面会话，登录档案持久化）、GitHub 工具面收敛为 github_shell

## 桌面安装包（Windows）

Claw 第一次以桌面应用的形态发布：双击安装器、走完向导即可使用——桌面版自带完整服务运行时，机器上没装 Node.js 也能跑；与 `npm start` 共用用户数据目录与默认端口。安装器由仓库根目录的「构建桌面安装包.cmd」产出，发布树要通过隔离端口冒烟自检才允许打包。

- **关窗不退场**：关闭窗口只是收进系统托盘，后台服务继续运行；随时从托盘恢复工作台，选择「退出程序」才会真正关闭服务
- **单实例激活**：重复运行 exe 只会激活已有窗口，不会开出第二份服务
- **与既有服务共存**：本机已有运行中的 Claw 服务时，桌面版启动后直接附着复用，不双开；退出时只关闭自己确认过的那个服务，绝不误关接管端口的其他进程。为此健康校验做得很严——HTTP 状态、ready、端口与进程 PID 全部对上才算数，退出前还会重新核对
- **权限不打扰**：桌面里的通知、麦克风、剪贴板权限直接放行，不逐项弹窗询问；这一待遇只给 Claw 自己的服务源（127.0.0.1），外部站点回落浏览器默认行为
- 用户数据与 Agent 工作区放在安装目录之外，重装升级不丢；应用图标全面更新，浏览器标签页接入同一套 favicon

## Feature 商店与挂载管理：能力装配自助化

为工作台扩充能力从此不必离开工作台。编程小助手的挂载管理页新增「添加 Feature」商店面板，安装、挂载、卸载在一处完成；旧 feature-repository 工作空间退役，其仓库管理与导入职能由新面板完整承接（历史会话仍可访问）。

- **合并货架**：官方可选插件与用户 Feature 包（tgz）同货架呈现，按功能类型分组；卡片展示能力声明面与中文名，已装配项（含缺失项）自动识别，不重复上架
- **安装即挂载**：点击安装即走统一的解析、环境准备与装配链；失败快速报错，不静默降级；卸载同样在面板内完成
- **装配与配置同源**：从仓库装配的 Feature 以 `$mount` 声明挂在配置树同一文件里——全局 / agent / coder 三层可分别装配，没有第二套装配心智
- **playwright_shell 率先转为官方可选插件**：主身份与 coder 身份均可一键挂载
- **面板重组**：Features 面板与挂载管理同源改版——按功能类型分组折叠、能力多值筛选接运行时真相、分页带计数、卡片补齐技能与命令数量

## 后台任务面板

构建、测试、开发服务器这类长命令，现在可以托管给后台，不再占住一次对话调用。

- **长命令转后台**：后台命令按双节奏汇报——正常运行最坏每隔一段固定时间送达一条进度，长时间无输出会主动提醒「还在跑」；前台调用超时自动转入后台继续执行，不再被中断
- **终端式卡片**：后台任务在右侧面板以终端式卡片呈现——标题行、命令与限高输出区、结果信息落卡片底部；卡片可折叠
- **打断与催报**：卡片上一键打断；「立即汇报」不等下一节奏，手动触发一次增量汇报
- **rail 徽标**：右侧 rail 的面板图标实时显示运行中的后台任务数
- 面板经新的 Feature-Panel 通信通道驱动：运行时 Feature 与前端面板之间的声明式实时通道（ADR-0018），后台任务面板是首个接入者，更多面板将陆续迁移到这条通道

## 轮次挂起：等待成为一等语义

后台任务派出后，Agent 的这一轮对话怎么算「结束」？此前的答案是假报「已完成」。本版本引入轮次挂起语义（ADR-0019）：回合自然结束但仍有待唤醒的后台任务时，结束状态为「挂起」而非「完成」。

- 对话区指示块持续显示等待中的后台任务数与已等待时长；唤醒轮开始即终止挂起文案，不跨入运行轮
- 待唤醒任务只是运行时事实，不写入上下文与检查点——回滚到更早节点后，挂起语义依然正确
- **Agent 不必守着后台任务干等**：派出任务、约好到点检查后即可结束这一轮，时间到了自动唤醒继续；等待期间任何一次汇报先到，等待目的即告达成
- 工具面同步重构（开发者向）：`bg_wait` 改为订阅一次到点检查，立即返回、等待由推送系统承载，不占用调用槽位；`bg_control` 拆分为 `bg_tune` / `bg_write` / `bg_kill` 三个动词，一个意图一个名字

## 跨对话记忆（Beta）

编程小助手可以读取历史会话的内容，把之前对话中的上下文带进当前任务。当前为 Beta 阶段，主链路已可用，持续打磨中。

- **会话引用（推荐）**：点击输入框「+」选择「会话」，或直接把左侧列表中的会话**拖拽**到输入框——引用以胶囊形式挂在输入框上，随下一条消息结构化投递，发送失败自动归还
- **按需读取**：Agent 收到引用后先查看该会话概览，再按需深入具体轮次——与当前任务无关的部分不占用上下文窗口
- **复制 Session ID**：左侧会话列表右键菜单与对话页顶部会话信息两个入口；把 ID 告诉 Agent（如「读一下这个会话：<ID>」）同样可以定位读取
- Beta 提示：对上下文特别长的历史会话，检索可能不够充分，部分内容不一定能被读取到，检索质量在持续提升

## 指南工作空间

新增「AgentDevClaw 指南」工作空间：内置使用指南开箱可读，不必再翻仓库文档。

- 左侧目录、右侧正文的阅读器形态，涵盖快速上手、模型配置、会话与上下文等主题，随版本演进持续更新
- 阅读体验：callout 提示块、上下篇导航、锚点跳转、图片点击缩放、内嵌视频演示

## Agent Studio 工作空间重做

上游制造端整轮重做，从功能堆叠转向以项目为中心。

- **项目中心**：首页以项目为组织中心，每个项目有固定的身份与独立的运行环境（历史记录自动迁移）；项目与 Feature 仓库两个视图，用户 Feature 仓库与下游商店共用同一份，tgz 上传后即时可见
- **开发工具链实测验选**：Studio 会实测本机可用的 Node / npm 组合（随包 / 系统 / 自定义路径），选定后按项目记住，脚手架创建、依赖安装、构建与快照打包全程沿用——不要求机器上有源码仓库，桌面安装环境同样可用。开发者可经 `studio_detect_environment` / `studio_select_toolchain` 两个工具直接驱动这套流程
- **会话按项目归类**：在 Studio 里创建的会话记录所属项目，分支与续接自动继承，列表按项目过滤

## 消息实时推送（SSE）

消息链路做了一次底层升级：会话事件（新消息、运行状态变化等）由服务端经事件通道**主动推送**到浏览器，前端事件驱动消费。

- 与既有轮询**灰度并行**：事件通道与轮询协同工作、可平滑回退，稳定性优先于切换速度
- 无变化时零请求；Worker 心跳按连接状态分流，多会话挂机几乎零冗余流量
- 经多轮对抗审查加固：连接边界、事件序、通知误报等一批隐患在上线前清偿——焦点会话的输入请求不再误报「需要你的选择」桌面通知

## 执行到此处：计划执行控制的整合

计划（任务列表）原有的两个执行控制粒度错位：全局「任务未完自动继续」开关只管「不许中途停」，单项「完成后停止」断点只管「到了就停」却不保证到达——职责重叠，且都无法表达「必须推进到某项后再停」。本版本统一为任务项上的单一控制：**执行到此处**。

- 设置后，Agent 必须推进到该任务完成：未到达而试图收尾时，注入推续提醒驱动继续（连续 3 次上限，防止打转）
- 目标任务进入终态即停止，断点自动清除
- 目标是最后一个未完成任务时解除断点、让本轮自然收尾——先标记完成、再输出总结汇报的节奏不再被机械拦腰打断

## 领域工具扩充

- **playwright_shell**：让 Agent 操作真实浏览器。一次性取证（截图 / PDF / 网络抓包）与多步受控会话（导航、点击、填表、下拉、标签页）两类动词，适合网页验证与登录后操作
- **登录档案持久化**：`--profile` 登录档案让登录态跨会话留存——首次人工登录一次，之后无头复用，登录站点的取证与操作不再每次重来
- **github_shell**：GitHub 操作（仓库、PR、Issue、Actions）收敛为一个领域 shell——受限动词表 + 白名单调用语法，能做什么、以什么参数做都受约束、可审计
- **coder_shell 检索增强**：线程列表默认返回 10 条，支持按目录 / 状态 / 标题过滤

## 工具过程呈现重做

工具调用过程是工作台里信息密度最高的区域，本版本做了整体重做。

- **调用卡与结果卡同构**：调用与结果两类卡片同一副骨架——标题条用次级文字色并以下划分隔线隔离，正文区主文字色，统一玻璃底色；Diff 视图不再叠一层多余的文件卡片
- **折叠语义统一**：过长的结果默认收起（不再只限 Read / Edit）；超长调用参数在卡内折叠，与所在行的收起互不牵连；一行里同时有可折叠内容时只有一处折叠按钮，不会套娃；展开过的状态会被记住，切走再回来还在
- **专属展示样式**：后台任务有结构化全景表和终端输入式卡片，bash 启动参数一目了然；读图结果显示图片信息；网页抓取正文可折叠；文件搜索的长结果随聊天滚动，不再困在小窗里；diff 行号栏补上底色，横向滚动不再透出代码鬼影。（开发者向：样式由框架 withDisplay 双通道的渲染模板提供——模型读到的文本逐字节不变，变的只是呈现层）

## claw CLI：长任务自接力

- **上下文自接力**：无人值守长任务触达上下文预算时，在进程内自动轮换上下文继续执行，不再中途断气
- **错误自动接续**：限流、网络抖动等可重试 API 错误自动接续重试，无需人工重新发起
- 执行底座默认装配，收敛为输出守卫与上下文轮换触发器两个模块，agent 装配保持可组合

## 时间感知

Agent 现在对时间有感知：对话进行中会周期性获知当前时间，隔了很久再回来时，也不会拿着过时的上下文假设继续干活。编程小助手与 IM 门户代理都已具备。

- 时间同步有节奏，不是每轮都报一遍——距上次超过 4 小时才告知一次系统时间与时区，并说明对话并非匀速进行、中间可能有用户离线的时间
- 距上一轮对话超过 24 小时，Agent 会额外收到提醒：用户可能已在其他会话推进相关工作、系统可能重启、项目环境可能变化
- 时间记忆随会话保存，按会话隔离、跨重启存活

## 性能

- **长会话窗口化渲染**：导航时间线只渲染可视窗口附近的对话行，千条消息级会话滚动依旧流畅
- **展开后流式不卡顿**：长会话展开显示过程后，流式输出只处理尾部变化。此前每条消息事件都触发全量扫描与多次强制布局，是展开后持续卡顿的主体
- **挂机内存更稳**：忙碌会话的面板事件缓冲有了字节预算，后台任务面板不盯着看时徽标只取运行计数——长时间挂着多个会话，内存不再悄悄上涨
- **少做无用重绘**：会话没有工具内容或展示样式已就绪时，不再整段重建历史对话
- **发送即回显**：用户消息乐观显示，发送后立即轮询——从发送到看到 AI 开始回应的等待明显缩短
- **会话操作提速**：分支 / 精简响应更快（早响应与去重）；会话索引进程内缓存，侧栏轮询不再重复解析大索引
- **流量治理**：HTTP 出口启用 gzip 压缩；静态资源 ETag 协商缓存；焦点轮询去除重复请求

## 模型与调用

- **调用超时改空闲语义**（框架侧）：模型调用不再受总时长上限，只按流式空闲判定超时——长输出、深度推理的调用不再中途被掐断
- **模型配置治理**：同名 provider 预设回显修复；Base URL 误带端点路径后缀时自动剥离（配置面板与适配器两侧对齐）；连接测试按面板当前输入的地址进行，而非已保存配置

## 安全与数据

- **前端第三方库本地化**：前端依赖的第三方库全部改为本地挂载，不再请求任何 CDN——内网与离线环境完整可用，也不向第三方泄漏访问事实
- 全局安全响应头；本地化资源经白名单路径暴露
- **配置归位**：应用级配置统一迁入用户数据目录，首次启动自动迁移；对话导出改写用户数据目录临时区，不再依赖服务启动目录

- 下线 feature-repository 工作空间：职能由 Feature 商店面板与装配链完整承接（见「Feature 商店与挂载管理」一节）
- 隐藏 flow-workspace 与 dispatch-console 工作空间入口
- 图片附件取消 10MB 大小限制
- MCP 自定义服务器支持单独启用 / 禁用
- history-only 精简在上下文末尾注入精简注解，Agent 对精简边界可见

## 问题修复

以下均为 v0.2.1 及更早版本中存在的问题：

### 会话与线程

- 紧凑 / 重启会话后前端出现「幽灵会话」条目
- 待发送气泡跨会话残留、系统提醒混入其他输入身份
- 归档 / 精简 / 摘要 / 分支后，源会话条目随新会话出现即时退场，不再滞留
- 回退失败不再假报「调用中」，失败原因对用户可见
- 数分钟级长工具调用不再被线程监视误判卡死而中断
- 精简 / 接续后编辑文件不再无谓重读——文件修改时间基线随会话快照通用透传
- 顶部上下文栏与输入框的模型 / 思考强度显示错拍消除

### 远程连接（Beta）

- 远程会话发送图片附件丢失、预览 404
- 空连接快照不再把预制 Agent 身份误降级为外部代理
- 远程会话被后台任务唤醒时，发送按钮状态不再错拍

### 界面

- 跟随模式切回时的二次跳底闪跳
- 「刚刚完成」蓝灯改为离开会话或新一轮运行时才熄灭
- slash 菜单空态浮层悬挂、仅前缀过滤、命令吞正文三项交互修复
- 图片附件与 slash pill 的会话隔离
- 显示过程模式下新工具调用不自动折叠
- Feature tgz 上传弹窗内容被遮罩盖住
- 后台任务徽标与面板对不支持后台任务的会话不再刷 404 报错
- 长驻使用内存缓慢上涨——两处前端泄漏（图表卡片卸载后仍被持有、会话折叠与锚点状态只增不减）
- Windows 下项目下拉「打开文件夹」按钮失效

### 框架侧

- edit 工具模糊匹配加固：堵住「报告成功却写坏文件」的匹配通路
- grep 工具捆绑 ripgrep 兜底，无系统级 ripgrep 的环境同样可用
- DebugHub 断连重连去掉次数上限，日志链路不再永久哑掉
- 长驻运行内存更稳——后台任务输出只读取增量尾部，会话退出后相关观察者即时摘除

## 工程质量

- **import 循环依赖检查**：新增值级循环依赖在 CI 直接拦截，存量环以基线锁定逐步清偿
