# v0.1.9 更新公告

本次更新涵盖自 v0.1.8 以来的全部改进，包含 49 次提交。

本轮的核心变化围绕**工具生态扩展**与**长会话体验治理**两条主线展开。一方面，新增 MCP Gateway 中心化服务器、GitHub 集成、Generative UI 持久化交互面板三大特性，大幅拓展了 Agent 可触达的工具边界与交互表达能力；另一方面，针对长会话场景下浏览器 DOM 压力导致的卡顿冻结问题，引入了虚拟化窗口渲染与导航时间线，将显示过程模式的切换耗时从 22 秒降至 70 毫秒。

此外还包含并行工具执行标记、精简操作所见即所得、响应式布局、运行时状态指示器等方向的改进。

## 新特性

- **MCP Gateway — 中心化共享 MCP 服务器**：此前每个 Agent 独立连接各自的 MCP 服务器，配置分散且连接数翻倍。本版引入服务端中心化网关，由 Claw 主进程统一维护与上游 MCP 服务器的长连接，Agent 侧透明发现并消费网关代理工具：
  - 新增 `server/mcp-gateway/` 模块，`MCPGatewayManager` 维护每台上游服务器的持久 Client 连接，按请求创建无状态代理 `McpServer` 实例
  - 前端设置浮层新增网关管理面板，支持服务器列表浏览、添加/编辑/删除、启用/禁用切换、即时重启与状态查看；系统内置服务器（Claw MCP / Debugger MCP）从硬编码改为动态管理
  - 服务器详情视图展示传输方式、URL、工具列表与参数 schema
  - 框架侧 MCPFeature 自动通过 ProtoClaw 源发现网关，与传统 MCP 配置透明合并，无需 Agent 侧改动
- **Generative UI — 持久化交互面板**：Agent 现在可以向用户展示声明式构建的交互式 UI 面板（表单、选择器、表格、代码块等），面板独立于聊天消息存在，用户可本地填写表单而不触发 Agent 调用，仅在点击提交按钮时才产生用户消息。面板生命周期独立于上下文——即使经过上下文精简（compaction）或消息裁剪（trim），面板依然存活：
  - 新增 `local-features/generative-ui`，包含组件目录（Stack / Row / Grid / Card / Table / TextInput / Select / Slider / Switch 等 20+ 组件）、Spec 校验器、Surface 生命周期管理与 Transport 层
  - 前端新增 `generative-ui-panel.js` 面板容器与 `generative-ui-renderer.js` 组件渲染器
  - 编程小助手已挂载该 Feature
- **GitHub 集成**：新增 `GitHubFeature`，为 Agent 提供 GitHub 平台的完整读写能力（32 个工具，按 6 个 toolset 分组：仓库上下文 / 仓库管理 / Issues / Pull Requests / GitHub Actions / 通知），直接调用 REST/GraphQL API，不依赖 MCP Server 或 gh CLI。认证策略为 PAT 优先 + gh CLI token 兜底；附带 `github-workflows` 技能引导 PR review 处理、CI 排查与发布变更
- **聊天消息导航时间线**：聊天区域左侧新增竖向导航条，每条对应一条 user 消息。hover 时波形展开并显示消息预览卡片，点击跳转到对应消息，滚动时实时追踪高亮当前位置。为长会话快速定位提供视觉锚点
- **运行时状态指示器**：当 Agent 活跃且「显示过程」关闭时，聊天区底部自动出现临时状态块，展示当前阶段标签、正在执行的工具名称与参数摘要（如 `bash: npm test`、`read: src/index.ts`）以及已用时间；Agent 完成后自动移除。运行时状态栏同时显示流式构建中的工具名（如「准备工具 · read, edit」）
- **响应式布局**：新增窄屏适配（≤1100 / 860 / 540px 三级断点），侧边栏在小屏下自动切换为覆盖式抽屉模式；Feature 面板窄宽时自动切换为单列显示
- **面板拖拽缩放**：右侧面板拖拽手柄移除 tooltip，拖拽超过最小宽度时释放即折叠（带迟滞阈值防抖动）；内容在折叠区内隐藏为纯背景
- **并行工具执行标记**：将 15 个只读查询工具标记为 `parallelizable: true`（群聊管理员工具 10 个、Generative UI 2 个、对话导出 1 个、IM 接线员 2 个），使这些无副作用的查询工具可与同批次其他只读工具并发执行
- **精简/分支预览展示上下文字符占比**：精简与分支对话框每轮展示字符数、占比、累计占比，将系统 preamble 纳入分母使合计为 100%，帮助用户直观判断精简前后上下文释放比例

## 调整

### 聊天显示性能大幅优化

本轮针对长会话（134K+ DOM 节点）在「显示过程」模式下的严重卡顿做了系统性治理：

- **虚拟化窗口渲染**：toggle 显示过程时只渲染视口附近约 70 行，远处行保持 `display:none` 不参与布局与绘制；滚动时通过 rAF 节流的 scroll listener 增量更新窗口边界，仅处理进出窗口的行而非全量遍历
- **折叠状态同步执行**：消除 rAF 延迟导致的展开/折叠闪烁
- **虚拟滚动 shimmer 修复**：隐藏工具行的占位符不再触发异常重绘，系统行排除出工具可见性路径
- **手动展开保护**：用户手动展开的行不受自动折叠逻辑干扰

toggle 性能：22 秒 → 71ms（约 300 倍提升）

### 其他调整

- **Choice Card 重新设计**：`ask_user_choice` 交互卡片改为双联布局——左侧可展开的决策背景面板 + 右侧问题与选项；新增「跳过并打断」按钮（Esc 触发）；选项区内部可滚动，header 和 footer 始终可见；玻璃质感渐变背景 + inset 高光
- **运行时指示器视觉打磨**：增大字号、微调 shimmer 动画、添加圆点与竖线装饰元素；通过 DOM diff 更新而非 innerHTML 重建来保持 CSS 动画连续性；MutationObserver 在指示器更新期间暂时抑制，消除视口抖动
- **面板折叠改为瞬间 snap**：侧边栏与右侧面板的折叠/展开从 CSS 宽度过渡动画改为瞬间生效，消除动画过程中的掉帧
- **Feature 面板视觉更新**：Badge 样式刷新、工具 schema 可展开查看、修复滚动位置重置问题
- **工具卡片样式统一**：Feature 详情与 MCP 网关采用统一的工具卡片视觉风格
- **编程小助手系统提示词精简与打磨**：多轮迭代精简提示词冗余内容，并回退部分过度精简以保持功能完整性
- **OutputGuardFeature 安全网**：编程小助手在 Context Guard 之后挂载 OutputGuardFeature，作为工具输出的兜底截断层，防止单次工具输出过大撑爆上下文
- **对话区底部留白增大**（200px → 250px），为输入框留出更多空间
- **升级 agentdev 框架**（v0.2.10 → v0.2.11）

## 问题修复

- **Trim 操作按 turn 粗粒度裁剪**：面板 UI 按每条 user 消息独立展示轮次，但同一 turn 内的多个 user 消息（如排队输入）共享相同 turn 值，原 trim 按 turn 操作无法区分。新增 `preservedMsgRanges` 字段使用消息数组索引 `[start, end]` 闭区间精确保留，实现所见即所得
- **重复精简丢失折叠工具摘要**：折叠后的工具活动笔记（folded-tool-activity）在二次精简时被误丢弃。新增 tag 白名单检查，带 `folded-tool-activity` 标签的系统消息在精简时始终保留
- **ASR 误将压缩音频当作原始 PCM**：ffmpeg 转码失败时，回退逻辑将 webm/opus 二进制数据包装为 Int16 PCM WAV 头，产生 ASR 无法处理的垃圾音频。改为直接发送原始压缩格式并附带正确 MIME 类型，同时捕获 ffmpeg stderr 用于诊断
- **重启后首次新建对话思考强度显示异常**：新建对话时未从 preset 读取 thinkingEffort，导致显示为「不支持思考」
- **语音输入在非安全上下文中报错**：通过远程 HTTP（非 localhost、非 HTTPS）访问时 `navigator.mediaDevices` 为 undefined，抛出晦涩的 TypeError。添加前置检查并给出中英双语提示，指向 HTTPS 或 SSH 端口转发方案
- **运行时指示器导致视口抖动**：指示器 DOM 更新触发的 MutationObserver 回调引起布局抖动，更新期间暂时抑制观察器
- **聊天容器左侧内边距不足**：导航时间线与聊天内容发生视觉重叠，增大 `chat-container` 左侧 padding
