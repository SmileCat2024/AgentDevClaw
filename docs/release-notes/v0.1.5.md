# v0.1.5 更新公告

## 新特性

- **Remote Claw 远程连接器**：新增 EmbeddedRemoteClawConnector，支持通过中继服务器远程连接本地 Claw 实例。具备心跳保活、会话快照增量同步（基于 content-hash diff）、远程命令执行（message.send / runtime.interrupt）能力；前端设置面板支持配对码配对与局域网 URL 自动发现，手机扫码即可远程操控
- **上次未关闭会话恢复**：Claw 重启后自动检测上次未关闭的会话，编程小助手首页展示恢复卡片，支持单个恢复、全部恢复、忽略三种操作；会话标题与目录实时刷新，不再依赖写入时的快照
- **群聊管理员态势感知全面升级**：
  - 新增**工作线程态势面板**，以会话血缘链为主线展示每个 Agent 的工作脉络——活跃会话标题、血缘深度、推断阶段（探索 / 编码）、运行时状态与任务摘要一目了然，支持展开查看完整链路与任务详情
  - 新增**会话血缘追踪**：branch / compact / summary 等衍生操作自动建立血缘关系，`session_continued` / `session_archived` 生命周期事件注入管理员 catch-up 上下文
  - 新增三个血缘感知工具 `gc_session_threads`、`gc_session_tasks`、`gc_session_summary`，管理员可按工作线程而非扁平列表查阅群聊全局态势
  - 新增**任务完成自动通知**：调度追踪器轮询 TODO 端点，检测到新完成任务时自动写入事件并主动通知管理员，无需人工轮询
  - 新增**群聊实时长轮询**，群聊写入时即时推送变更，替代高频轮询
  - 新增 `gc_stop` 工具与**强制显式完成**机制：`gc_dispatch` / `gc_reply` 新增必填 `done` 参数，`done=true` 时通过 `@StepFinish + Decision.Deny` 终止 call 循环，Agent 尝试无工具调用结束时自动注入提醒——多重保障防止管理员任务完成后空转
  - 建群时**强制指定项目目录**，`gc_dispatch` 新增 `openDirectory` 参数，新会话默认在群聊绑定目录下创建
  - 移除低效的周期性身份提醒注入，改由系统提示词 + 强制完成约定兜底
- **侧栏与导航体验全面重构**：
  - 编程小助手运行时会话按**项目分组**显示，支持折叠展开与字母序排列
  - 工作群侧栏从平铺管理员列表改为**按群聊分组**
  - 项目分组标题与群聊标签 hover 显示「进入」按钮，点击直接跳转对应工作空间——新增 `navigateToWorkspaceSession` 统一跨工作空间会话导航
  - 左侧四个分类标签（系统空间 / 工作群 / 工具与效率 / 外部代理）均支持折叠收起
  - 工作群侧栏与主区域之间新增**折叠按钮**，收起后对话区占满全宽
- **导航守卫**：引入全局 epoch 计数器，用户主动导航时递增，异步操作在执行延迟跳转前检查——若用户已离开则静默取消，不再被过期操作拉回
- **桌面通知增强**：`user_input` choice 工具触发时后台同样弹出系统通知（复用 call 结束通知的保护机制）；修复桌面 finish 通知延迟与连续任务完成被吞的问题
- **语音录音提示音零延迟化**：从 `new Audio().play()` 改为 Web Audio API 预解码 AudioBuffer，实现近零延迟播放；发送按钮添加重入保护
- **Feature 面板淡入动画**：面板打开时容器宽度过渡先于内容渲染执行，消除宽度和内容同时变化导致的视觉跳动

## 调整

- **Magic Numbers 统一治理**：将散落在 session.js、agent-lifecycle.js、group-chat.js、dispatch.js、call-arbiter.js、app-main.js 等 15+ 文件中的硬编码超时、轮询间隔、续段预算等关键数字提取至 `server/shared/constants.js` 和 `app-core.js` 集中管理
- **work-group-ui.js 模块化拆分**：将 4357 行的单一文件拆分为 7 个领域模块（wg-state / wg-voice-input / wg-annotations / wg-context-menu / wg-settings-panel / wg-popover / wg-core），约 50 个闭包变量提取为共享 WgState 对象
- **管理员上下文阈值调整**：Token 上限从 100k 提升至 200k，压缩触发比例从 80% 调整至 20%
- **服务端原子归档**：branch / compact_and_resume / summary_resume / compacted_resume 四个端点新增 `archiveOriginal` 标志，服务端在返回响应前完成归档，消除客户端竞态窗口；响应携带结构化归档结果，失败时前端回滚乐观状态
- **中文聊天文本渲染稳定化**：聊天渲染签名从简单字符串拼接改为稳定序列化 + hash，解决中文内容因编码差异导致签名不一致时的渲染抖动
- **升级 agentdev 至 v0.2.6**；修正 qqbot-feature tgz 引用（0.00.0 → 0.2.0）

## 问题修复与优化

- **会话标题自动生成系列修复**：修复衍生会话（分支/精简/摘要）标题不触发的根因——`getAutoTitleSessionInfo()` 读取 host agent session 而非当前 runtime session，改为优先通过 `currentRuntimeAgentId` 查找；新增 `_derivedBaseline` 机制替代旧的空消息守卫；放宽最后消息检查允许 tool 结尾；修复服务端 `createPrebuiltSession` 不读 `options.title` 导致前置括号标题不生效；修复 seed 注入未落盘导致 title mirror 子进程 ENOENT；增加 `hasUserMessage` 检查防止空对话误触发
- **PROTOCLAW_HANDOFF_PATH 环境变量泄露**：服务端从携带该变量的 runtime 内重启时（如 ShellFeature 执行 `npm start`），变量泄露进 `process.env` 并被后续所有子进程继承，导致新会话被注入旧 handoff 内容。新增 `childProcessEnv()` 辅助函数在所有 6 个 spawn 点剥离会话级环境变量
- **跨会话操作 calling 状态中断误触发**：用户执行 trim/branch/compact 时旧 runtime 的 calling 状态不应触发中断 UI，在 runtime-status、input-helpers、persistent-input、voice-input、app-main 五处添加抑制检查
- **群聊切换后长轮询永久死亡**：`AbortError` catch 块无条件 return，切换群聊后不再调度下一轮。改为 fall through 到 `_pollingActive` 检查
- **Rollback 后草稿输入框不显示**：`_sessionInputCache` 中残留空字符串导致 `initialValue` 预填被跳过，改为检查值非空而非键存在
- **Windows 路径大小写不一致**：多处 session 创建路径未规范化大小写，导致前端按目录分组时出现 `Test` 与 `test` 分离。新增共享 `normalizePathCasing()` 覆盖 trim/compact/summary/branch/ph_project 全链路
- **幽灵模型预设**：`config/default.example.json` 中 `defaultModel` 包含不存在的模型名，新部署首次启动注入幽灵文本模型。改为空对象，前端 5 处硬编码 fallback 同步清除
- **loadAgents 合并丢失新建会话**：已加载 agent detail 时直接丢弃 `get_connected_agents` 返回的 sessions 数组，导致群聊 dispatch 创建的会话在侧栏不可见。改为按 ID 合并
- **消息折叠功能失效**：`COLLAPSE_THRESHOLD` 在模块拆分时被误转为 WgState 属性，还原为模块常量
- **语音录音模式追踪竞态**：`lastRenderedInputMode` 在更新后才被读取，导致模式比较的总是新值而非旧值
- **weixin-bot 轮询日志噪音**：旧 tgz dist 每次轮询迭代输出两条日志，源码已移除但 tgz 未重建

## AgentDev 框架升级（v0.2.5 → v0.2.6）

- **edit/write 工具加固**：新增文件 staleness 校验（比对 mtime），强制 read-before-write，修复 Read 去重返回过期内容（Edit/Write 后使旧条目失效），Write 工具强制 LF 行尾避免跨平台损坏，模糊匹配成功时返回警告
- **MCP Feature 三个问题修复**：路径基准从 `process.cwd()` 改为 `ctx.config.workspaceDir`；配置加载层归一化 `type` → `transport`，兼容 Claude Desktop / Cursor 等标准 MCP 客户端；stdio 连接从手动 spawn + 裸 JSON-RPC 改为 `StdioClientTransport + Client.connect()`，完成 MCP 初始化握手
- **技能文件扫描简化**：从递归扫描改为仅扫描一级目录结构，兼容根目录直接放置 `SKILL.md`
