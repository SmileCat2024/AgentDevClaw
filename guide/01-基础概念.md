# 基础概念

在动手之前，先建立几个核心概念的心智模型。

## 工作空间

工作空间是 AgentDevClaw 的功能单元。每个工作空间聚焦一件事：AI 编程对话、Feature 制造、IM 消息接入等。左侧列表就是全部工作空间的入口。

## 会话

会话是一次具体的交互过程。会话绑定一个项目目录，Agent 的所有工具操作都在这个目录下进行。会话可以分支、精简、checkpoint 管理。

## Feature 与 Agent

- **Feature** 是一个能力包，提供工具、界面块或工作流。Shell 命令、Web 搜索、待办清单、各 IM 渠道，都是一个 Feature。
- **Agent** 是 Feature 的装配体：多个 Feature 组合出一个完整的智能体。

| 概念 | 类比 | 说明 |
| --- | --- | --- |
| Feature | 插件 | 提供独立能力 |
| Agent | 宿主 | 组合 Feature 并暴露交互入口 |
| Runtime | 进程 | Agent 的运行实例 |

## 配置的三个层级

每个 Feature 都有自己的参数，参数按三个层级组织：**全局 → 工作空间 → 目录**，越具体的层级越优先，下层覆盖上层同名配置。

1. **全局**：右下角设置菜单中的「全局 Feature 设置」，是所有工作空间共享的默认值。
2. **工作空间**：工作空间卡片上的「工作空间设置」，只对该工作空间生效，并按身份分层（如编程小助手与 Coder 各自一层）。
3. **目录**：项目条上的「目录设置」，只对单个项目目录生效。
