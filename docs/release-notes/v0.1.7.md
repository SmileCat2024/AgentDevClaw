# v0.1.7 更新公告

本次更新涵盖自 v0.1.5 以来的全部改进，包含 73 次提交，涉及跨平台支持、上下文安全防护、群聊管理员线程化、前端架构大规模重构、工程质量管理等多个方向。

## 新特性

- **完整 Linux 跨平台支持**：通信管道按平台自动选择，文件选择器在非 Windows 环境回退为内置 Web 目录浏览器，无需系统原生对话框即可完成项目目录选择与文件浏览
- **Context Guard 上下文安全防护**：实时监控会话上下文 Token 用量，当接近模型的压缩阈值时自动中断会话并锁定输入区域，防止 Agent 在超长上下文下产生幻觉或崩溃
- **Rokid AR 眼镜（乐奇眼镜）IM 渠道**：新增第 5 个 IM 渠道，通过配对码与 WebSocket 建立与 Rokid RCS 服务的连接；前端「更多渠道」折叠分组中展示
- **图片读取能力**：编程小助手与 IM 渠道均支持 Agent 读取用户发送的图片并注入对话上下文；修复精简/分支场景下图片附件丢失的问题
- **Feature 状态连续性自声明协议**：第三方 feature 无需修改 Claw 中心代码即可参与会话状态捕获与恢复，状态转移不再局限于预置白名单
- **侧栏会话列表索引化**：会话状态读取统一到单一数据源，引入时序追踪与诊断机制，终止态会话不再出现幽灵交互
- **群聊管理员线程化重构**：
  - 管理员视角从扁平会话列表改为**以工作线程为主线**，每个 Agent 的活跃会话标题、血缘深度、推断阶段与运行时状态一目了然
  - 工作线程**生命周期态势面板**精细化，展示更完整的线程状态流转
  - 管理员输出信息更清晰，线程区域支持折叠，减少视觉噪音
  - 线程控制与管理员提醒机制优化，任务派发与完成通知更精准
- **编程小助手右键菜单增强**：新增「删除会话」选项；同时移除重启/关闭操作的二次确认弹窗，减少打断

## 调整

### 前端架构大规模模块化拆分

本轮对前端三大膨胀文件执行了系统性拆分，总计将约 2 万行单体代码拆分为 30+ 个领域模块：

- **编程小助手前端**：Feature 配置面板、Todo Plan 面板、会话列表渲染、右键菜单处理、侧栏渲染、输入请求渲染等模块独立化；核心入口文件从 6600 行瘦身至 1200 行
- **群聊前端**：从 4600 行拆分为纯函数、数据层、格式化、会话解析、派发核心、态势感知 6 个模块，降至 1800 行
- **服务端**：Agent 生命周期、会话管理、IM 配置、调度引擎、工作空间等模块均完成职责分离
- **会话视图统一**：前端会话数据的读取、写入、提交重构为单一管线，消除多路径竞态

### 其他调整

- **网络代理设置独立面板**：从模型设置中拆出为独立入口，新增代理检测卡片与状态提示
- **模型设置 UI 改进**：预设标签改为样式化文本；OAuth 登录面板改为扁平布局；未选中预设时自动选择第一个；切换标签页时高度不再跳动
- **群聊文件原子写入**：消除并发写入或进程崩溃时文件损坏导致群聊从列表中静默消失的问题
- **群聊会话区布局加宽**：消息列表、Agent 消息体、任务卡片宽度均增大，宽屏空间利用率提升
- **Remote Claw 连接器健壮性**：轮询循环增加指数退避与日志抑制，中继服务器不可达时不再刷屏日志
- **静态资源禁缓存**：所有前端资源以 no-store 方式提供，消除浏览器缓存导致的旧版本残留
- **升级 agentdev 框架**（v0.2.6 → v0.2.8）

## 问题修复

- **Shell 命令 stderr 未截断**：超长 stderr 不再导致上下文膨胀
- **模型预设 maxTokens 零值**：校验拒绝无效的 maxTokens 配置，防止框架 fallback 到默认 4096
- **Codex OAuth 登录修复**：OAuth 流程正确路由至 Responses 传输层，viewer 请求不走代理通道
- **Agent 中断信号不稳定**：中断改为粘性机制，确保在异步操作中不会被意外清除；语音输入路径同步加保护
- **折叠工具摘要角色错误**：精简折叠的工具活动摘要不再被 LLM 误认为自己说过的话
- **分支不兼容新版 checkpoint 格式**：兼容 v1/v2 两种检查点格式
- **会话精简后上下文不同步**：Seed 消息按角色正确分发，修复 Feature 查询与快照一致性问题
- **Feature 详情弹窗定位错误**：弹窗不再跟随面板滚动，固定在视口中央
- **上下文用量条闪烁**：页面刷新或 Agent 切换时间歇性显示默认值，现已稳定
- **无头 Linux 环境 opener 崩溃**：添加异常防护
- **网关子路径部署**：修复反向代理子路径场景下的资源路径问题
- **群聊会话恢复后欢迎态丢失**、**群聊路由依赖未初始化**等多个时序问题修复
- **ESLint 扫描发现的预存 bug**：会话搜索引用未定义常量、作用域外变量、已移除的接口调用等 4 处运行时隐患修复
- **全项目 87 处空 catch 块**：统一补充错误日志输出，空异常吞没清零

## 工程质量

- **ESLint 基础设施**：全项目接入静态检查，覆盖前端 JS、服务端脚本与 TypeScript feature 源码；接入 pre-commit hook，提交前自动执行 lint + 核心测试
- **测试覆盖大幅扩展**：新增约 500 个前端纯函数测试用例与 29 个跨平台测试；总计 83 个测试文件、约 1850 个断言全部通过（v0.1.5 为约 1027 个）
- **TDD 驱动的模块提取**：调度引擎、会话刷新、工作空间三个核心模块在拆分过程中采用测试先行，确保行为一致性
