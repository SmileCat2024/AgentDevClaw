# v0.2.3 更新公告

本次更新涵盖自 v0.2.2 以来的改进：OpenAI 登录新增浏览器授权主流程，前端挂机流量治理再下一程。

## OpenAI 登录：浏览器授权成为首选

- **浏览器授权登录**（新增主入口）：对齐 Codex CLI 官方 `codex login` 的默认流程——点击后自动打开授权页，完成授权自动回跳本机回调端口继续登录，全程无需复制粘贴
- 回调服务器只绑定 127.0.0.1，PKCE S256 + 随机 state 防 CSRF；授权参数与官方 CLI 完全一致（同一 client_id，授权页表现相同）
- **设备码登录保留为备选**：远程访问工作台（本机无需打开浏览器）等场景仍可使用

## Feature 配置：多值字段跨层叠加

- `skill.extraDirs` 这类累加型多值字段：目录层配置自己的技能目录，不再把 agent 层的组织级目录整个顶掉——多层贡献折叠为并集（上游在前、精确去重）（ADR-0020）
- 配置编辑器以只读块展示上游条目并标注来源层，本层输入框只承载本层条目；运行时与 UI 预览同源

## 性能：挂机与多会话的流量治理

- **无焦点页面降频**：不在会话焦点上的页面，agent 列表拉取从每秒一次降为 30s 兜底（agent 增删仍即时驱动），实测空闲页带宽降约 30 倍
- **远程目录空转门控**：没有任何远程连接时，目录轮询降为 30s 发现心跳；目录状态未变时不重渲染侧栏
- **后台任务徽标事件驱动**：面板关闭态徽标不再每 3s 发两个请求，任务增减经 SSE 即时反映
- **线程列表增量门控**：内容未变化时短路返回，~100KB 级聚合结果不再每次轮询全量传输；新旧服务端与前端可独立部署

## 工程质量（开发者向）

- **桌面安装包版本单一来源**：版本号唯一来源收敛到根 package.json，构建前自动同步进 tauri.conf.json 与 Cargo.toml，发版只改一处版本号
- **OAuth 回调页加固**：provider 返回的 error / error_description 转义后再渲染，消除本地回调页的反射注入面
